<strong>Job Overview</strong><p>We’re hiring an <strong>AI Architect</strong> to design and govern the end-to-end architecture for AI solutions spanning multi-agent orchestration, knowledge-graph reasoning, retrieval-augmented generation (RAG), and evaluation at scale. You will define model strategy, reasoning patterns, data interfaces, and safety/guardrails; establish reusable blueprints; and partner with engineering, security, and data teams to deliver reliable, explainable, and cost-effective AI capabilities.</p>
<strong>Key Responsibilities</strong><ul><li><strong>AI Architecture &amp; Patterns:</strong> Define reference architectures for LLM-powered systems (planner/reasoner, router/composer, tool/connector mesh), including typed I/O contracts and failure isolation.</li><li><strong>Knowledge &amp; Retrieval Strategy:</strong> Architect coexistence of <strong>Knowledge Graph</strong> reasoning and <strong>RAG</strong> baselines; select embedding/vector stores, chunking, retrieval/reranking, and subgraph/query patterns.</li><li><strong>Model Strategy &amp; Routing:</strong> Establish model selection policies (small→large escalation), prompt/adapter patterns, caching, and cost/latency budgets; document routing outcomes.</li><li><strong>Evaluation &amp; Quality Gates:</strong> Design test sets and scoring rubrics (faithfulness/correctness, precision/recall, multi-hop coverage, latency); implement automated re-evaluation on any change (model/agent/prompt/data).</li><li><strong>Safety &amp; Guardrails:</strong> Specify policy-as-code, entitlement checks (role/row/column), PII/PHI handling, and content moderation; define red-team tests and jailbreak defenses.</li><li><strong>Data &amp; Interfaces:</strong> Define schemas for AI inputs/outputs; guide ontology/taxonomy alignment; ensure provenance/lineage for KG/RAG pipelines; minimize data movement.</li><li><strong>Operability &amp; Observability:</strong> Standardize tracing/logging/metrics for AI runs (call graphs, token/latency/cost); set SLOs and error budgets; partner with DevOps for CI/CD and environment promotion gates.</li><li><strong>Technical Leadership:</strong> Review designs/PRs; mentor AI engineers; communicate decisions/trade-offs to stakeholders; maintain decision records and roadmaps.</li></ul>
<strong>Required Skills</strong><ul><li><strong>Applied LLM Systems:</strong> 1+ years in ML/AI or platform architecture with production LLM solutions (planning/reasoning, tool use, function-calling, agent ecosystems).</li><li><strong>Knowledge &amp; Retrieval:</strong> Hands-on with <strong>Knowledge Graphs</strong> (RDF/SPARQL or property graph/Gremlin) and <strong>RAG</strong> (chunking, embeddings, retrieval/reranking); practical trade-offs between the two.</li><li><strong>Model &amp; Vector Ecosystem:</strong> Experience with at least one major model platform (Azure OpenAI, Vertex AI, Anthropic, open-weights) and vector DBs (pgvector, Pinecone, Weaviate, Milvus) plus search (OpenSearch/Elasticsearch).</li><li><strong>Evaluation Engineering:</strong> Ability to construct evaluation harnesses, design rubrics, and automate regression testing; familiarity with A/B testing and human-in-the-loop review.</li><li><strong>Security-by-Design:</strong> SSO/OIDC, secrets management, least-privilege design, policy-as-code, data minimization, and auditability for AI systems.</li><li><strong>Software &amp; APIs:</strong> Strong API design (REST/gRPC), JSON schema contracts, error taxonomies, retries/backoff/idempotency; proficiency in one or more languages (Python, TypeScript/Node.js, Go, or Java).</li><li><strong>Observability &amp; Reliability:</strong> OpenTelemetry or equivalent for traces/metrics/logs; resiliency patterns (circuit breakers, bulkheads, backpressure); performance tuning and cost governance.</li></ul>
<strong>Good to Have Skills</strong><ul><li><strong>Ontology &amp; Graph Practices:</strong> SHACL, OWL, ontology stewardship, and data quality checks; graph query optimization and subgraph extraction patterns.</li><li><strong>Prompt &amp; Tooling Ops:</strong> Prompt versioning, prompt injection defenses, retrieval parameter tuning, and structured tool-use schemas (e.g., MCP-style adapters).</li><li><strong>MLOps &amp; Platforms:</strong> IaC (Terraform), CI/CD for models/prompts/configs, feature flags, canary releases; experience with GPU/accelerator considerations.</li><li><strong>External Tools:</strong> Designing safe, auditable action patterns and HITL approvals for external tool execution (simulation/models, document generation, ticketing).</li><li><strong>Cost/Performance Analytics:</strong> Token accounting, cache strategies, and per-agent cost ceilings; dashboards for cost-per-answer and latency P50/P95 targets.</li><li><strong>UX for Explainability:</strong> Collaborating on rationale/explanation UX so users understand sources, subgraphs, and model/tool decisions.</li></ul><p>This role suits a hands-on architect who blends rigorous evaluation and safety with practical engineering patterns-enabling reliable, explainable AI at enterprise scale.</p>
