**Job Summary**
---------------

We are looking for a talented Software Development Engineer II with a passion for Artificial Intelligence to help design, develop, and deploy intelligent applications and scalable machine learning systems. You will work closely with other developers, data scientists, ML engineers, and product teams to bring cutting-edge AI capabilities into real-world applications.

As a mid-level contributor, you will have ownership over feature development, participate in architectural discussions, and ensure systems are performant, maintainable, and scalable.

This position requires a mix of strong technical and functional skills, leadership ability, and a deep understanding of agile software development practices.

**Responsibilities**
--------------------

*   Design, develop, test, and maintain high-quality software solutions
*   Build a solid AI-driven customer engagement product using the Google CES solution
*   Collaborate with product managers, designers, and other developers to define and deliver new features
*   Optimize model performance and system latency across distributed environments
*   Experience with API design and backend development using REST or gRPC
*   Conduct code reviews, mentor junior developers, and uphold coding best practices
*   Implement and monitor CI/CD pipelines and model deployment workflows
*   Work in Agile teams and contribute to sprint planning, estimation, and reviews

**Qualifications**
------------------

*   Bachelor’s or Master’s degree in Computer Science, Software Engineering, or a related field
*   Minimum 4 years of software development experience
*   Good hands-on experience on Python, JavaScript, GIT, NodeJS, GIT and Code Blocks
*   Experience with Google CES, along with prompt engineering, is an added advantage
*   Experience with Google Cloud capabilities
*   The person should be a strong team player
*   The person should be in the Dallas/Fort Worth area and ready for the hybrid work culture (3 days in the office)
