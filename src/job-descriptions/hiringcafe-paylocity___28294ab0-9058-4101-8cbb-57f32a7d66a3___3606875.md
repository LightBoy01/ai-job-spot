Description

hc1 Insights is looking for a skilled Software Engineer to design, develop and install software solutions, with a specialized focus on building AI driven solutions. The successful candidate will be able to build high-quality, innovative, and fully performing software in compliance with coding standards and technical design. In this role, you will design, modify, develop, write, and implement software programming applications.  You will also participate in testing through test review and analysis, test witnessing, and software certification.

  

You need to work independently with little supervision. Have the ability to prioritize well, communicate clearly, possess a consistent track record of delivery, and demonstrate excellent software engineering skills. You must be able to work across multiple facets of the project and juggle multiple responsibilities simultaneously.

  

**What you'll do:**

*   Full-stack development
*   Design, develop, and implement scalable AI and machine learning models
*   Build and maintain robust, high-performance machine learning pipelines for model training, evaluation, and deployment in a production environment
*   Integrate AI models and solutions into existing software applications via APIs or embedded code
*   Optimize AI algorithms and models for improved performance, scalability, and efficiency
*   Participate in code reviews, documentation of design, and implementation of Agile methodologies to ensure high quality software
*   Troubleshoot and fix software application problems
*   Participate in software process quality efforts
*   Complete other duties as assigned

Requirements

**What you bring:**

*   A four-year degree in Computer Science, Engineering or related field
*   2+ years experience with software design and development
*   Experience with Gen AI technologies, LLMs, and agent frameworks
*   Experience with Prompt engineering
*   Proficiency in Python and its associated AI/ML libraries (e.g., scikit-learn, Pandas, NumPy)
*   Solid understanding of core AI concepts, including supervised and unsupervised learning, deep learning, and neural networks
*   Experience developing modern web user interfaces
*   Demonstrated troubleshooting and problem solving skills
*   Professional skills in working with various relational database systems
*   Ability to work both independently and in small team environments

**Our tech stack:**

*   Programming languages: Java, Python, React, JavaScript, SQL
*   AI Technologies: AWS Bedrock, Sagemaker
*   Container technologies: Docker, ECS
*   Amazon Web Services (AWS): EC2, SQS, S3, Lambda
*   Web Services REST API’s
*   Databases: MySQL, PostgreSQL, DynamoDB
*   Continuous integration tools (Github, Jenkins, TravisCI, Artifactory, JIRA)
*   Agile principles (Scrum): scrum master facilitated ceremonies: planning, backlog grooming, daily stand-ups, demo and retro
