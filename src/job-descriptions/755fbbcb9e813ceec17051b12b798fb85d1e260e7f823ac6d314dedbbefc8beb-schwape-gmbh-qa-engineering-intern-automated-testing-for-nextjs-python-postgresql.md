Taleroo is a modern learning & talent platform built on a full-stack environment using **Next.js**, **Python/Flask**, and **PostgreSQL**. We manage complex user flows, AI-powered recommendations, and dynamic dashboards and we want to elevate our QA processes to the next level.

We’re looking for a **QA Engineering Intern** who is serious about automated testing, software quality, and modern CI/CD workflows.

Tasks
-----

*   Build automated **frontend tests** for our Next.js application (Playwright or Cypress)
*   Write **backend API tests** for our Flask services using PyTest
*   Validate **PostgreSQL models**, SQLAlchemy queries, and migration flows
*   Develop **regression test suites** that cover core user journeys
*   Integrate test suites into **GitHub Actions** and help improve CI/CD pipelines
*   Reproduce, document, and prioritize bugs together with the engineering team
*   Write clear documentation for test cases, processes, and QA guidelines

Requirements
------------

*   Understanding of web system architecture (frontend + backend + database)
*   Some experience with **Next.js/React**, **Python/Flask**, and relational databases
*   Basic familiarity with testing frameworks (Playwright, Cypress, Selenium, PyTest)
*   Comfortable writing tests in both **JavaScript** and **Python**
*   Structured, detail-oriented mindset and a willingness to intentionally break things to improve stability
*   Bonus: experience testing **AI features**, data pipelines, or MLOps flows

Benefits
--------

*   Hands-on QA engineering experience in a real production environment
*   Work across the full stack: Next.js, Flask, PostgreSQL, and AI-driven features
*   Direct mentorship from experienced engineers working with modern tech stacks
*   Flexible remote schedule
*   Your work will have a real impact: faster release cycles, fewer manual tests, higher product stability

If you love modern test automation and wants to help shape QA at Taleroo, we’d love to hear from you. Your work will directly strengthen our testing infrastructure and help us ship cleaner, more reliable features.
