As a (Sr.) Frontend Engineer, you will be responsible for designing, developing, testing, deploying, and supporting high-quality software solutions. This role involves close collaboration with architects, project managers, developers, QA, and UI designers to develop products that satisfy customer needs, solve their problems, and achieve customer success.

**Your Mission**

*   Leverage AI-assisted development tools (e.g., GitHub Copilot, ChatGPT or MCP servers) to boost development speed, enhance code quality, and accelerate prototyping.
    
*   Collaborate closely with stakeholders on requirement discussions, cross-team integration, and issue resolution.
    
*   Deliver features through the full development lifecycle, including planning, design, implementation, testing, deployment, and operation.
    
*   Create and execute test cases and scripts to validate software functionality, performance, reliability, and security.
    
*   Troubleshoot and debug complex issues by identifying root causes and implementing effective solutions.
    
*   Automate and enhance development and release processes to improve efficiency and reliability.
    

**What We’re Looking For**

*   Bachelor’s degree in computer science, engineering, or equivalent industry experience.
    
*   Familiarity with one of the programming languages (e.g. JavaScript, TypeScript).
    
*   Familiarity with one of the frontend frameworks and libraries (e.g. React, Redux, jQuery, Vue.js, Node.js)
    
*   Familiarity with testing frameworks (e.g. Selenium, pytest and Robot Framework).
    
*   Familiarity with browser internals, rendering process, and HTTP protocol
    
*   Familiarity with version control systems (e.g. Git) and CI/CD processes (e.g. GitHub Action)
    

**Extra Skills We Love**

*   Experience in container solution (e.g., Docker) 
    
*   Solid grasp of modern front-end tools, workflows, and best practices (e.g., bundlers, component-based architecture)
    
*   Able to quickly identify UI/UX issues and implement scalable, maintainable solutions
    
*   Experience in test management platforms (e.g.TestRail)
    
*   Able to visualize design and test logic to improve test coverage and catch edge cases.
    

**Culture Fit**

*   Everyone owns both development and testing — quality is built, not just tested.
    
*   Embraces DevOps culture including design, coding, testing, and support customer issues
    
*   Good English communication skills and proactive attitude, strong problem-solving skills, and a willingness to take on challenges.
    
*   Effective communicator and reliable team player in agile and cross-functional environments
