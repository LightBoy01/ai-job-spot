Airbyte is the open-source standard for Data Movement. We enable data teams to move data from applications, APIs, unstructured sources, and databases to data warehouses, lakes, AI applications and LLMs. With our approach we are finally solving the need for extensibility and control that every company needs with data.

&nbsp;

So far, our customers, users, and ourselves have built over 15,000 connectors and have had 200,000+ companies install Airbyte. We've raised $181M from the world's top investors (Benchmark, Accel, Altimeter, Coatue, Y Combinator, etc.) and we believe in product-led growth, where we build something awesome that all our users love.

&nbsp;

We’re committed to providing as much context to our current employees and candidates.&nbsp;The Airbyte&nbsp;company handbook is open to all.

&nbsp;

If you find this role exciting, we encourage you to apply even if you think you don’t meet all requirements.





<p><strong>Opportunity:</strong></p>
<p>As a Senior Software Engineer on our Database Sources team, you'll tackle one of the most valuable problems in data engineering - building a delightful and repeatable process for creating database integrations at lightning speed and enterprise quality.</p>
<p>Growing our database portfolio is one of our biggest revenue opportunities this year. You'll be building cutting-edge frameworks and leveraging LLMs to automate integration development, while going deep into database internals to extract maximum performance from every system. You will be architecting the framework that will make Airbyte's database sources the industry leaders.</p>
<p><strong>Revolutionary Database Technologies You'll Build:</strong></p>
<ul>
<li><strong>AI-Powered Integration Framework&nbsp;</strong>- Build intelligent systems that leverage LLMs to generate database integrations, reducing development time from weeks to hours</li>
<li><strong>Advanced Change Data Capture (CDC) Engine</strong> - Engineer sophisticated CDC solutions using write-ahead logging and real-time data streaming that capture database changes with microsecond precision</li>
<li><strong>High-Performance Query Optimization </strong>- Deep-dive into database internals, optimized queries,and information schema management to build the fastest data extraction systems in the industry</li>
<li><strong>Next-Generation Database Connectors </strong>- Create production-ready integrations that handle terabytes of data while maintaining enterprise-grade reliability and security</li>
<li><strong>Intelligent Schema Management</strong> - Build frameworks that automatically adapt to database schema changes and optimize data pipeline performance in real-time</li>
</ul>
<p><strong>What You'll Do:</strong></p>
<ul>
<li><strong>Build core technologies</strong> managing Airbyte's fleet of high-volume database connectors powering thousands of enterprise customers</li>
<li><strong>Architect a framework </strong>that makes connector development 10x faster while driving innovation across the data engineering industry</li>
<li><strong>Write high-leverage code </strong>that directly enables Airbyte's rapid growth and market leadership in database connectivity</li>
<li><strong>Mentor brilliant engineers</strong> while collaborating with our 800+ contributor community - the largest open-source data engineering ecosystem</li>
</ul>
<p><strong>What We're Looking For:</strong></p>
<ul>
<li><strong>An insatiable desire to ship </strong>- you're driven by seeing your code power real-world data infrastructure at massive scale</li>
<li><strong>6+ years of software engineering </strong>building production systems that handle enterprise workloads&nbsp;</li>
<li><strong>Performance optimization expertise</strong> - you've optimized high-performance applications and understand moving terabytes efficiently</li>
<li><strong>Deep database curiosity</strong> - you want to master PostgreSQL, MySQL, Oracle, and other systems at an architectural level and find clever solutions to difficult problems</li>
<li><strong>DevEx obsession</strong> -constantly improving your development setup to eliminate redundant tasks</li>
<li><strong>AI-first mindset </strong>- you’re already using AI tools and see LLMs' potential to revolutionize software development</li>
</ul>
<p><strong>Nice to Have:</strong></p>
<ul>
<li><strong>JVM expertise</strong> - 2+ years of experience with Java, Kotlin, or Scala (we use Kotlin for our backend systems)</li>
<li><strong>Open-source contributions</strong> - active participation in database or data engineering projects</li>
<li><strong>Enterprise database experience</strong> - hands-on work with Oracle, SQL Server, or other mission-critical database systems</li>
</ul>
