We co-founded and led Viafintech (Barzahlen) to 100+ FTE , one of the most successful German fintechs, active in 17 markets across the EU and USA, and sold it in 2021 for a € three-digit million amount to NYSE-listed Paysafe Group.

Now we’re off to our next venture. This time we’re building a global champion for prepaid products: gift cards (Apple, Amazon, Google), airtime and eCash all in one simple API. Think of finperks as a stripe/adyen for all prepaid products and payments.

We started in summer 2025 and in just a few months we have already onboarded 700+ brands, and our first client goes live by the end of the year.

Many people completely underestimate the market size: about €600bn sold per year today, going to €1.8tn by 2028.

Instead of 5 players in the chain (brand → issuing tech provider → global distributor → local distributor → client), we connect brands directly with clients via the finperks platform. Today 95% of prepaid is still sold in the Global North; we believe that for the gig economy to monetize the Global South, prepaid will be key - from Netflix and Google to Apple and Uber.

We’re a team of 8 in Berlin-Charlottenburg. A mix of our best people from the last journey and brilliant new joiners. High ownership. Low ego. Kind humans. We ship fast, help each other, and celebrate wins.

Join early. Help build the global champion for prepaid.

Tasks
-----

As a Software Engineer, you'll build the core platform that connects global brands with clients across multiple markets.

You will:

*   Build intuitive, responsive dashboards for clients to manage gift card inventory, track transactions, and access analytics in real-time
*   Create developer-friendly interfaces for API integration, and testing tools that make client onboarding seamless
*   Enable internal teams with purpose-built UIs that enhance operational efficiency and provide clear insights into system activity
*   Design and implement reusable React components with clean APIs that scale across our product suite
*   Connect frontend applications to our backend APIs, handling state management, error scenarios, and loading states elegantly
*   Collaborate with product and design to create interfaces that are not just functional but delightful to use
*   Optimize application performance, minimize bundle sizes, and ensure fast load times
*   Ensure all interfaces work flawlessly across desktop, tablet, and mobile devices
*   Write clean, maintainable code with comprehensive tests and participate in code reviews
*   You'll focus on frontend, but you'll occasionally work across the full stack - we're a small team where backend engineers ship UI fixes and frontend engineers optimize queries when needed

Requirements
------------

**You'll need:**

*   **React Expertise:** 3+ years building production React applications with strong understanding of hooks, component lifecycle, and modern React patterns
*   **JavaScript/TypeScript:** Solid foundation in JavaScript (ES6+) and experience with TypeScript
*   **State Management:** Experience with state management solutions (Redux, MobX, Zustand, or Context API)
*   **API Integration:** Proven experience integrating with RESTful APIs and handling async operations
*   **Styling:** Strong CSS skills and experience with modern styling approaches (CSS Modules, Styled Components, Tailwind, etc.)
*   **Build Tools:** Familiarity with modern frontend tooling (Webpack, Vite, npm/yarn)
*   **Version Control:** Proficient with Git workflows and collaboration practices
*   **Problem Solver:** You enjoy translating complex requirements into intuitive user interfaces
*   **Communication:** Strong English skills; German is a plus

**Nice to have:**

*   Experience in FinTech, SaaS platforms, or developer tools
*   Knowledge of testing frameworks (Jest, React Testing Library, Cypress)
*   Understanding of web performance optimization techniques
*   Experience with data visualization libraries (Recharts, D3.js, Chart.js)
*   Familiarity with AWS services and cloud deployment
*   Basic understanding of backend technologies and APIs (our backend stack: Ruby and Golang)
*   UI/UX design sensibility
