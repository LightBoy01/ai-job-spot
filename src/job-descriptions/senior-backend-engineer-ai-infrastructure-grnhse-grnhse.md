<p><strong>The opportunity</strong><br>At Unity, we’re shaping the future of real-time 3D by applying machine learning to revolutionize how games are created and experienced. From neural rendering to on-device inference optimization on high-end mobile devices, we’re building the next generation of ML-powered graphics pipelines that enable faster, more immersive, and more efficient 3D game development.</p>
<p>We are looking for a versatile, self-driven Senior Backend Engineer who can work across different levels of abstraction and contribute as an active technical leader. In this role, you will design, build, and maintain backend systems that support advanced ML-powered tools, including asset generation and LLM inference, to enable AI-assisted game creation.</p>
<p><strong>What you'll be doing</strong></p>
<ul>
<li>Design, build, and maintain backend services and APIs that support AI-powered game authoring tools</li>
<li>Develop scalable, high-availability systems used across Unity’s ML and AI ecosystem</li>
<li>Collaborate with engineers, data scientists, and product managers to deliver new features and ML-driven experiences</li>
<li>Improve performance, reliability, observability, and cost-efficiency of backend systems</li>
<li>Contribute to architectural decisions and technical direction of AI and backend platforms</li>
</ul>
<p><strong>What we're looking for</strong></p>
<ul>
<li>Proven experience building backend services at scale</li>
<li>Proficiency in C# / .NET</li>
<li>Familiarity with cloud infrastructure and observability tools (e.g. Kubernetes, Grafana, etc.)</li>
<li>Understanding of API design, distributed systems, and system reliability</li>
<li>Strong understanding of software development best practices, a quality-first mentality and approach</li>
</ul>
<p><strong>You might also have</strong></p>
<ul>
<li>Experience in ad tech, programmatic advertising, or real-time bidding systems</li>
<li>Background with infrastructure-as-code (e.g., Terraform)</li>
<li>Familiarity with networking, caching, or real-time data pipelines</li>
<li>Exposure to ML infrastructure or LLM inference deployment</li>
<li>Familiarity with Unity or similar 3D engines</li>
<li>Familiarity with languages like Python, Golang</li>
</ul>
