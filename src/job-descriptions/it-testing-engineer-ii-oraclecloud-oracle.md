<p><b>IT Testing Engineer II</b>&nbsp;</p>
<p>&nbsp;</p>
<p><b>About the Role</b><b>:</b>&nbsp;</p>
<p>Conduent is&nbsp;seeking as&nbsp;IT Testing Engineer to Conduent tests on our software systems to ensure functional and&nbsp;optimal performance.&nbsp;</p>
<p>&nbsp;</p>
<p><b>Responsibilities</b><b>:</b>&nbsp;</p>
<ul>
 <li>Analyze user needs and test software solutions using agile&nbsp;methodology&nbsp;</li>
 <li>Create test models for release testing (plans,&nbsp;data and scripts) including the&nbsp;identification,&nbsp;collection and/or creation of test data&nbsp;</li>
 <li>Lead co-ordination and execution of release testing as appropriate  &nbsp;</li>
 <li>Determine and meet time estimates and schedules for testing efforts  &nbsp;</li>
 <li>Define Release Test Plans and criteria for user acceptance including entry/exit criteria  &nbsp;</li>
 <li>Develop,&nbsp;update and&nbsp;maintain quality testing standards and procedures  &nbsp;</li>
 <li>Communicate effectively with customers and software vendors as appropriate  &nbsp;</li>
 <li>Assist in the planning,&nbsp;creation and control of the test environment(s)  &nbsp;</li>
 <li>Follow standard testing&nbsp;methodology frameworks, testing processes as a standard  &nbsp;</li>
 <li>Co-ordinate testing specific release activities  &nbsp;</li>
 <li>Determine and meet time estimates and schedules for testing efforts  &nbsp;</li>
 <li>Create test models for release testing (plans,&nbsp;data and scripts) pate in structured walk-through and peer reviews  &nbsp;</li>
 <li>Participate in the coordination and execution of release testing  &nbsp;</li>
 <li>Update and test release installation procedures  &nbsp;</li>
 <li>Participate in Lessons Learned as appropriate  &nbsp;</li>
 <li>Identify defects and questionable functionality; manage defects through to closure  &nbsp;</li>
 <li>Resolve issues with unclear requirements and achieve a successful result  &nbsp;</li>
 <li>Triage and solve complex problems using structured troubleshooting methodologies  &nbsp;</li>
 <li>Quick learner, work independently as well as work collaboratively in a team environment  &nbsp;</li>
</ul>
<p>&nbsp;</p>
<p><b>Basic Qualifications for Consideration</b><b>:</b>&nbsp;</p>
<p>&nbsp;</p>
<ul>
 <li>Minimum of 5+ years of experience as Senior QA  &nbsp;</li>
 <li>Experience in&nbsp;creation of test&nbsp;plan, test estimates, test schedules and implementing test strategies &nbsp;</li>
 <li>Solid experience in writing SQL statements for data validations  &nbsp;</li>
 <li>Solid experience in Database and Batch Job testing &nbsp;</li>
 <li>Ability to design, develop, test and debug tests cases/Scripts/plans/strategy documents   &nbsp;</li>
 <li>Minimum four (4) years’ experience working on project(s) involving the implementation of software development life cycle(s) (SDLC).  &nbsp;</li>
 <li>Preparation of Defect Status Reports and Daily/Weekly Status Reports. &nbsp;</li>
 <li>Knowledge of&nbsp;Health Insurance Industry is&nbsp;a must – Pharmacy, Claims processing, PBM, ICD 9/10, Medicare, or Medicaid.  &nbsp;</li>
 <li>Knowledge of Azure and Confluence. &nbsp;</li>
 <li>Document and interpret business and technical requirements for testing&nbsp;utilizing various development methodologies (e.g. Agile, Scrum, Iterative, Waterfall, etc.)  &nbsp;</li>
 <li>Extensive experience in Test Management tools building Test Plans and Test Cases using tools like JIRA, Xray and Azure DevOps (VSTS) &nbsp;</li>
 <li>Hands on experience in Excel and Status Reports. &nbsp;</li>
 <li>Effective communication skills to articulate testing result data to multiple audiences.  &nbsp;</li>
 <li>Working knowledge on AI tools for automation. &nbsp;</li>
 <li>Working knowledge of industry standard automated testing tools, practices, and software and/or Performance testing tools.  &nbsp;</li>
</ul>
