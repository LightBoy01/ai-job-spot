**About Job**

Overview The AI Engineer is responsible for debugging and troubleshooting SQL databases. They create scripts and macros for delivery optimization and use cloud computing for data processing. The AI Engineer performs complex data processing tasks including custom web crawling and pattern detection activities. Some management experience required. Duties and Responsibilities • Platform-to-client handoff/handback support for a variety of data formats. • Working with SQL databases including debugging and troubleshooting. • Using cloud computing platforms such as AWS, Azure, and GCP for data processing tasks. • RPA application to existing processes. • Creating scripts and macros for optimizing delivery pipelines. • Perform complex data processing tasks including custom web crawling, data type specific content cleanup, and pattern detection activities. • Additional duties as assigned. Requirements • Advanced knowledge of Regex and scripting for batch data optimization and cleanup. • Engineering level of understanding of data validation principles. • Basic knowledge of cloud computing frameworks including Azure Cognitive Services, AWS, etc. • Working knowledge of SQL including troubleshooting/debugging. • Advanced knowledge of syntax of most common file formats such as XML, JSON, RESX, Properties, CSV, etc. • Advanced knowledge of text processing software tools such as EmEditor, Sublime Text, Beyond Compare, Notepad++ • Advanced platform-to-client handoff and handback support for a variety of data formats • Ability to handle a variety of data formats including multi-domain solutions to process such data. • Willingness to work overtime if necessary. • Remote, office, or hybrid work environment depending on specific position. • Excellent attention to detail. • Ability to multi-task in a deadline driven environment. • Quick learner. • Problem-solver with a strong sense of initiative. • Excellent written and oral communication skills in English. • Leadership qualities including the ability to give/take feedback, recognition of when to delegate, and confidence.
