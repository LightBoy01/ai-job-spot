Description
      
<p>hc1 Insights is looking for a skilled Software Engineer to design, develop and install software solutions, with a specialized focus on building AI driven solutions. The successful candidate will be able to build high-quality, innovative, and fully performing software in compliance with coding standards and technical design. In this role, you will design, modify, develop, write, and implement software programming applications. &nbsp;You will also participate in testing through test review and analysis, test witnessing, and software certification.</p><p><br></p><p>You need to work independently with little supervision. Have the ability to prioritize well, communicate clearly, possess a consistent track record of delivery, and demonstrate excellent software engineering skills. You must be able to work across multiple facets of the project and juggle multiple responsibilities simultaneously.</p><p><br></p><p><strong>What you'll do:</strong></p><ul><li>Full-stack development</li><li>Design, develop, and implement scalable AI and machine learning models</li><li>Build and maintain robust, high-performance machine learning pipelines for model training, evaluation, and deployment in a production environment</li><li>Integrate AI models and solutions into existing software applications via APIs or embedded code</li><li>Optimize AI algorithms and models for improved performance, scalability, and efficiency</li><li>Participate in code reviews, documentation of design, and implementation of Agile methodologies to ensure high quality software</li><li>Troubleshoot and fix software application problems</li><li>Participate in software process quality efforts</li><li>Complete other duties as assigned</li></ul>
        
Requirements
        
<p><strong>What you bring:</strong></p><ul><li>A four-year degree in Computer Science, Engineering or related field</li><li>2+ years experience with software design and development</li><li>Experience with Gen AI technologies, LLMs, and agent frameworks</li><li>Experience with Prompt engineering</li><li>Proficiency in Python and its associated AI/ML libraries (e.g., scikit-learn, Pandas, NumPy)</li><li>Solid understanding of core AI concepts, including supervised and unsupervised learning, deep learning, and neural networks</li><li>Experience developing modern web user interfaces</li><li>Demonstrated troubleshooting and problem solving skills</li><li>Professional skills in working with various relational database systems</li><li>Ability to work both independently and in small team environments</li></ul><p><strong>Our tech stack:</strong></p><ul><li>Programming languages: Java, Python, React, JavaScript, SQL</li><li>AI Technologies: AWS Bedrock, Sagemaker</li><li>Container technologies: Docker, ECS</li><li>Amazon Web Services (AWS): EC2, SQS, S3, Lambda</li><li>Web Services REST API’s</li><li>Databases: MySQL, PostgreSQL, DynamoDB</li><li>Continuous integration tools (Github, Jenkins, TravisCI, Artifactory, JIRA)</li><li>Agile principles (Scrum): scrum master facilitated ceremonies: planning, backlog grooming, daily stand-ups, demo and retro</li></ul>
