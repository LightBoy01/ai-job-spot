**Basic Function**
Under moderate supervision, designs, develops, tests, debugs and deploys moderately complex customer-intent software solutions, along with creating and supporting software tools and utilities required for the operation, maintenance, and control of the software system.  Makes moderately complex modifications to existing software to fit specialized needs and configurations and maintains program libraries and technical documentation. Assists in planning, scheduling and implementation and initiates corrective action(s) to stay on schedule.
You will develop and maintain **UI applications and back end services** that consume agentic AI workflows using TypeScript, React.js, and NodeJS. You will craft effective prompts for generative AI models and create autonomous AI agents in Python. Your role will involve implementing security best practices, optimizing UI performance, and ensuring cross-browser compatibility. You will participate in Agile development processes, peer code reviews, estimation, and sprint planning.
**Essential Duties and responsibilities**
*   Develop and maintain UI applications that act as consumer of **agentic ai workflows using typescript, React.js and NodeJS**
*   **Prompt engineering skills**; crafting effective inputs (prompts) to guide generative AI models (like ChatGPT) to produce desired outputs.
*   **Experience with creating agentic AI in Python**. This involves creating autonomous AI agents that can perceive their environment, make decisions, and take actions to achieve specific goals also using large language models (LLMs) and / or a willingness to learn this.
*   Implement security best practices for web applications, including authentication and authorization mechanisms
*   Experience with observability preferably creating insights into agentic workflow’s.
*   Optimize UI performance, build responsive applications and ensure cross-browser compatibility
*   Participate in Agile development, peer code reviews, estimation and sprint planning
