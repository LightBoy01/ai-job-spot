<strong>The role</strong>&nbsp;
<p>We are looking for a Security Operations Engineer to join out IT infrastructure team. You will be responsible for monitoring, detecting, and responding to security incidents across Microsoft Sentinel, Defender XDR, Entra ID, and Purview. This includes investigating threats, tuning detection, creating automation playbooks, and ensuring compliance with data protection policies. You will collaborate with IT, security, and compliance teams to strengthen the organization’s security posture and enable a proactive defense strategy.</p>
<p><strong>Your responsibilities:</strong>&nbsp;</p>
<ul>
<li>Monitor, investigate, and respond to security incidents across Sentinel and Defender XDR.</li>
<li>Administer, configure, and enhance Microsoft Sentinel (rules, playbooks, automation workflows).</li>
<li>Detect and respond to identity-based threats in Entra ID and enforce conditional access &amp; MFA policies.</li>
<li>Configure, monitor, and investigate alerts from Microsoft Purview (DLP, insider risk, compliance violations).</li>
<li>Perform threat hunting using Sentinel and Defender telemetry.</li>
<li>Tune detections and reduce false positives to increase SOC efficiency.</li>
<li>Create and maintain security automation (Logic Apps, PowerShell runbooks, Sentinel playbooks).</li>
<li>Provide reporting and documentation for incidents, investigations, and compliance requirements.</li>
<li>Collaborate with IT, SecOps, and compliance teams to improve detection coverage and response processes.</li>
</ul>
<p><strong>Must-haves:</strong>&nbsp;</p>
<ul>
<li>3+ years of hands-on experience with&nbsp;<strong>Microsoft Security technologies</strong>&nbsp;in enterprise environments.</li>
<li>Deep experience with:
<ul>
<li><strong>Microsoft Sentinel</strong>&nbsp;(KQL queries, analytic rules, automation playbooks, dashboards).</li>
<li><strong>Microsoft Defender XDR</strong>&nbsp;(Defender for Endpoint, Identity, Office 365, Cloud Apps).</li>
<li><strong>Microsoft Entra ID</strong>&nbsp;(identity protection, conditional access, PIM).</li>
<li><strong>Microsoft Purview</strong>&nbsp;(DLP, sensitivity labels, insider risk, eDiscovery).</li>
</ul>
</li>
<li>Strong understanding of identity and access management, authentication protocols (SAML, OAuth, OpenID Connect, Kerberos).</li>
<li>Knowledge of SIEM/SOAR concepts, incident response workflows, and the MITRE ATT&amp;CK framework.</li>
<li>Development/scripting experience using:
<ul>
<li><strong>Kusto Query Language (KQL)</strong></li>
<li><strong>PowerShell (primary)</strong></li>
<li>RESTful APIs / Microsoft Graph API</li>
<li>Python or Bash (nice to have).</li>
</ul>
</li>
<li>Strong troubleshooting and forensic investigation skills across endpoints, identities, and cloud workloads.</li>
<li>Intermediate written and spoken English is required.</li>
</ul>
