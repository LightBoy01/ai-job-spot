We are looking for a experienced Test Engineer to join our Telecommunication project

“QAE- 5GC IMS Voice & Messaging Engineer” is the role to manage and to work proactively to drive initiatives around the operational delivery capabilities. This role requires strong technical knowledge of understanding 3GPP specifications, deep knowledge of 4G and 5G- IMS Core Nodes which should primarily include P-CSCF, S-CSCF, TAS, IPSM-GW ,MRFC, MRFP, BGCF, MGCF, I-SBC, DRA, HSS, SMSC, architectural and design documents to come up with thorough and in-depth test plans for testing LTE EPC and 5G Core node functionalities.

Tasks
-----

**KEY RESPONSIBILITIES**

*   Creating test scripts using available test tools. This will involve getting familiarized with the test tools and figuring out innovative ways of re-creating practically possible scenarios.
*   Ability to build test setups as per the requirements of the test case and environment.
*   Executing test cases and validating the test status based on the expectations for the test case.
*   Ability to fully understand system logs, test tool logs and use this understanding for debugging issues and identifying accurate root causes for the problems seen on the system under test or in the network
*   Using the test expertise and identifying overall improvements and enhancements

**MINIMUM REQUIREMENTS (Knowledge, Skills, Abilities)**

Requirements
------------

*   **Minimum 8 to 15 years of experience**
*   Thorough knowledge and hands on experience of IMS Core Nodes which should primarily include **P-CSCF, S-CSCF, TAS, IPSM-GW ,MRFC, MRFP, BGCF, MGCF, I-SBC, DRA, HSS, SMSC**.
*   In-depth knowledge of IMS call flows as per 3GPPP.
*   Good knowledge on the IMS interfaces like **Gm, Rx, ISC, Ro, Sh, Mw, Ici, Izi**.
*   Good understanding of protocols like **SIP, Diameter, REST, TCP/IP, DNS, MSRP**.
*   Experience in with **SS7** application level protocols (MAP/CAP/INAP) is a plus.
*   Hands on Experience on testing E2E call flows with respect to **VoLTE and VoWiFi**.
*   Hands-On Experience in Test Strategy Preparation & Driving Testing Projects
*   Expertise in product /capacity testing using simulators/scripting /open source tools
*   Ability to create/build test setups as per the test strategy of the feature.
*   Executing test cases and validating the test status based on the expectations for the test case.
*   Ability to fully understand system logs, test tool logs and use this understanding for debugging issues and identifying accurate root causes for the problems seen on the system under test or in the network.
*   Expertise with core network simulated tools like Spirent Landslide.
*   Good understanding of NFVi Architecture and VNF Life Cycle Management.
*   Experience in K8S is a plus.
*   Working knowledge with Helm, json, yaml etc.
*   L2/L3 network and k8s Networking expertise CNIs like Calico and service mesh is a plus.
