**Job Description:**

Pilot's Senior AI Engineer will drive technical decisions, own complex projects, demonstrate deep expertise in AI/ML systems and mentoring junior engineers while delivering high-impact solutions.

Key Responsibilities & Scope

*   Technical Leadership: Leads complex projects and influences technical direction
*   Mentorship: Guides junior engineers and shares knowledge across teams
*   System Design: Architects scalable AI solutions with performance optimization
*   Cross-functional Impact: Collaborates with product, research, and platform teams

Full Stack Development

*   Architect end-to-end AI applications using modern web frameworks and cloud-native architectures
*   Lead implementation of complex front-end interfaces with advanced React.js patterns
*   Design robust backend services with event-driven architectures using AWS services
*   Implement gRPC and GraphQL microservices and optimize system performance
*   Ensure application security, performance optimization, and scalability across the full stack

Machine Learning Engineering & Operations

*   Design and optimize ML model deployment strategies for production scale
*   Establish MLOps best practices including automated testing and evaluation
*   Implement comprehensive monitoring using CloudWatch, Prometheus, and Grafana
*   Optimize model performance and cost efficiency
*   Lead infrastructure design with Terraform IaC and multi-cloud strategies

Applied Generative AI Research & Agent Development

*   Research and implement state-of-the-art generative AI models and agent architectures
*   Build sophisticated multi-agent orchestration systems
*   Develop advanced RAG systems with performance optimization
*   Create agent evaluation frameworks measuring performance, reliability, and safety
*   Drive prompt engineering strategies and multi-modal AI applications
*   Lead integration of LLM APIs and open-source models with optimization techniques
