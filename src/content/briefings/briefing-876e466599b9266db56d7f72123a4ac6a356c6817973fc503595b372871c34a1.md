<p>Welcome to <strong>Day 1 of the Statistics Challenge for Data Scientists.</strong><br><br>
In this series, we'll cover practical and essential statistical concepts that every data scientist should master.</p>

<p>Today's topic focuses on one of the most common challenges in data preprocessing - <strong>imputing missing values</strong>.</p>

<h2>
  
  
  Simplest Method to Impute Missing Values
</h2>

<div class="table-wrapper-paragraph"><table>
<thead>
<tr>
<th>Data Type</th>
<th>Method</th>
<th>When to Use</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>Numerical</strong></td>
<td>Mean / Median</td>
<td>Use <strong>mean</strong> when data is normally distributed. Use <strong>median</strong> when data has <strong>outliers</strong>.</td>
</tr>
<tr>
<td><strong>Categorical</strong></td>
<td>Mode</td>
<td>Use <strong>mode</strong> (most frequent value) to fill missing categories.</td>
</tr>
</tbody>
</table></div>

<p><strong>Example:</strong><br><br>
For a numerical column like <code>Age</code>, use <strong>median</strong> if there are extreme values (outliers).<br><br>
For categorical data like <code>Region</code> or <code>Category</code>, use <strong>mode</strong> to fill missing values.</p>

<h2>
  
  
  When to Avoid Mean/Median Imputation
</h2>

<p>While mean or median imputation is simple and quick, it isn't always the right approach.<br><br>
Avoid it when:</p>

<ul>
<li>A <strong>large percentage</strong> of data (e.g., &gt;20%) is missing
</li>
<li>The <strong>missingness depends on other features</strong> (not random)
</li>
<li>You can estimate missing values more accurately using other related variables
</li>
</ul>

<p>In such cases, use <strong>model-based or feature-driven imputation</strong>, which preserves data integrity and relationships better.</p>

<h2>
  
  
  Real-World Example: Manufacturing Client Case
</h2>

<p>For a <strong>manufacturing client</strong>, building a model to <strong>predict faulty truck parts</strong>.<br><br>
One critical feature is the <strong>distance covered (miles)</strong> by each truck - higher distance meant a higher probability of part failure.</p>

<p>However, about <strong>25% of the "miles" data was missing</strong>.<br><br>
Using median imputation would have distorted the original data distribution and affected model accuracy.</p>

<p>Instead, building a <strong>simple XGBoost model</strong> to predict missing mile values based on:</p>

<ul>
<li>Type of truck
</li>
<li>Region of operation
</li>
<li>Engine life
</li>
<li>Daily usage
</li>
</ul>

<p>This approach will maintain the true data pattern and produced more reliable imputations.</p>

<h2>
  
  
  Key Takeaways
</h2>

<div class="table-wrapper-paragraph"><table>
<thead>
<tr>
<th>Situation</th>
<th>Best Approach</th>
</tr>
</thead>
<tbody>
<tr>
<td>Small percentage of missing data</td>
<td>Mean / Median / Mode Imputation</td>
</tr>
<tr>
<td>Large percentage of missing data</td>
<td>Model-based or feature-driven imputation</td>
</tr>
<tr>
<td>Data has strong feature relationships</td>
<td>Predict missing values using related features</td>
</tr>
<tr>
<td>Data contains outliers</td>
<td>Use Median instead of Mean</td>
</tr>
</tbody>
</table></div>

<p><strong>Pro Tip:</strong><br><br>
Always visualize your data distribution before and after imputation.<br><br>
If the distribution changes significantly, reconsider your imputation method.</p>
