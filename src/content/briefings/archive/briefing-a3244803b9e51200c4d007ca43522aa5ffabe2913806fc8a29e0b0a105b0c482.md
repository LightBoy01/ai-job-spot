<img src="https://spectrum.ieee.org/media-library/conceptual-photo-illustration-of-agentic-ai-workflows-for-various-tasks.jpg?id=61740846&amp;width=2000&amp;height=1500&amp;coordinates=0%2C0%2C0%2C0"><br><br><p>The Internet as we know it could be on the cusp of dramatic change as autonomous <a data-linked-post="2669884140" href="https://spectrum.ieee.org/ai-agents">AI agents</a> become the primary users of the Web, researchers say. In a <a href="https://arxiv.org/abs/2507.21206">recent position paper</a>, a multi-institution team laid out their vision for how online infrastructure will have to adapt to the new reality of this “agentic Web,” and discussed the promise and peril of this transition.</p><p><span>While most people are already familiar with AI chatbots powered by <a data-linked-post="2672500550" href="https://spectrum.ieee.org/tag/large-language-models">large language models</a> (LLMs), tech companies are racing to develop AI agents capable of <a href="https://spectrum.ieee.org/ai-agents-computer-use">autonomously navigating the Web</a> to carry out tasks on behalf of users. If this dream becomes a reality, the Internet will increasingly be driven by machine-to-machine interactions as these agents coordinate to achieve the goals of their owners.</span></p><p><span>This situation would require a fundamental redesign of the Internet’s underlying architecture and would transform both everyday online experiences and the dynamics of the </span><a href="https://spectrum.ieee.org/ai-agent-economy">digital economy</a><span>. And while users could benefit in terms of convenience and efficiency, the changeover also holds the potential for major security risks.</span></p><p><em>IEEE Spectrum</em><span> spoke to one of the authors of the recent paper, <a href="https://dawnsong.io/">Dawn Song</a>, a professor of computer science at the University of California, Berkeley, and renowned expert on AI safety and security. Song talked about what a future agentic Web could look like and the implications of such a shift. </span></p><h2>The Coming of the Agentic Web</h2><p><strong>What is the agentic Web and how will it be different from today’s Web?</strong></p><p><strong>Dawn Song:</strong><span> If you look at the Web today, it’s very much designed for humans. The whole UI [user interface] is about how humans consume information, make decisions, and take actions on the Web. But agents don’t operate like humans, and they don’t have the same kind of limitations as humans, so the Web can be designed very differently.</span></p><p><span>In a traditional setting, if a user wants to buy a piece of clothing they will go to a website, type in what they want to buy, and then the website is going to show different choices. This design is limited by human constraints: A human has to be able to see the different pieces of clothing, and they can only see so much at the time, and then they need to scroll down the Web page.</span></p><p><span>But in the agentic Web, a user can have an agent that knows their intent and preferences, and the websites can have agents too. Then essentially the user’s agent can talk to the website’s agent, and they don’t have the same kind of limitations as users. The user can only see so much at the time, but the agent can consume so much more information. Today’s large language models can summarize thousands of articles in a matter of seconds in parallel.</span></p><p><span>Also with this agent-to-agent interaction, as the agent gets more information it can quickly decide what additional information it needs to get. Then it can send more requests and negotiate with the other agents. So the entire interaction will be completely different, and hence the interfaces will be completely different as well.</span></p><p><strong>What key technologies will underpin this future agentic Web?</strong></p><p><strong>Song:</strong><span> It’s really a ground-up redesign. The agents need to be able to understand user intent, and then from that need to be able to do planning and reasoning. And the agents need to interact with other agents, to get more information or potentially even do negotiations. So underpinning the agentic Web is, first, the strong capabilities of agents for all these different types of tasks.</span></p><p><span>The </span><span>entire infrastructure will also be very different. You have agent-to-agent communication, and agents may also use other agents for different services, so you need to have multiagent orchestration. So we need to design new protocols. There are already some good examples of open protocols for agents: the </span><a href="https://modelcontextprotocol.io/docs/getting-started/intro">MCP protocol</a><span> from Anthropic that enables tool use and the </span><a href="https://a2a-protocol.org/latest/">A2A protocol</a><span> from Google for agent-agent communication.</span></p><p><span>And we foresee that going into the future, we could benefit from new open protocols for agent payments and agent identity. These are core elements in the agentic Web. Agent identity is important so that you know which agent you are talking to and what kind of capabilities and privileges this agent may have. And payments, of course, are really important for the new agentic online economy, which will have its own characteristics.</span></p><p><strong>Will the entire internet transition over to this new model? Or will there be separate Webs for humans and agents designed on different principles?</strong></p><p><strong>Song:</strong><span> I think you are going to see a blend. Certainly there will be services that are more tailored for agents. But it’s not like humans will disappear from the Web. We want to continue to allow humans to directly interact with the Web as well. And oftentimes we are going to see humans and agents work together to complete tasks. So I think this new agentic Web and the traditional Web for humans will be connected and blended together.</span></p><h2>AI Agents Bring Efficiency, Productivity, and Security Risks</h2><p><strong>What are the pros and cons of this transition </strong><strong>to an </strong><strong>agentic web?</strong></p><p class="shortcode-media shortcode-media-rebelmouse-image rm-float-left rm-resized-container rm-resized-container-25" data-rm-resized-container="25%" style="float: left;"> <img alt="Smiling portrait of Dawn Song." class="rm-shortcode" data-rm-shortcode-id="b65a4f2c1851c52b7421364e27a17157" data-rm-shortcode-name="rebelmouse-image" id="21fe8" loading="lazy" src="https://spectrum.ieee.org/media-library/smiling-portrait-of-dawn-song.jpg?id=61740850&amp;width=980"> <small class="image-media media-caption" placeholder="Add Photo Caption...">Dawn Song believes that agentic AI brings unprecedented security risks.</small><small class="image-media media-photo-credit" placeholder="Add Photo Credit..."><a href="https://www.morgenstein.com/">Richard Morgenstein</a></small></p><p><strong>Song:</strong><span> We hope that there will be a lot of pros! Right now, if you look at the Web, there’s so much information, so many services, but humans are very limited. We are oftentimes the bottleneck. So we hope that the agentic Web can significantly improve the efficiency and productivity with which humans can utilize all these great resources. So users can get information much faster, get more relevant information, higher quality information, and can complete tasks much more efficiently. This could help the whole economy to be more efficient.</span></p><p><span>But we need to get this right; otherwise there are a lot of risks. It’s unprecedented that we have these autonomous agents operating on the open Web that can take actions, have high privileges, can buy things on behalf of the users, and so on. We need to be really mindful of these new safety and security risks.</span></p><p><strong>What are the main security concerns?</strong></p><p><strong>Song:</strong><span> This is uncharted territory, given the power and capabilities of these agents and their autonomy. This opens up much larger attack surfaces. Already, we know that <a href="https://spectrum.ieee.org/homomorphic-encryption-llm">LLMs have certain security vulnerabilities</a> and safety issues. Agents can also leak sensitive information about the users. So for example, they may know a user’s preferences, which can be very privacy sensitive. Or maybe credit card numbers or sensitive bank information.</span></p><p><span>Our work and others’ work have shown that these agents can <a href="https://arxiv.org/abs/2412.05734">be easily attacked</a> in ways that such <a href="https://arxiv.org/abs/2407.12784">sensitive information can be stolen</a>. Or agents can be made to take malicious actions against the user’s intent. Going forward in the agentic Web with more autonomous agents and with multiagent systems will only exacerbate these security issues.</span></p><p><strong>Given the technology’s maturity level and the scale of the security challenges, is an agentic Web viable in the near term? Are people really going to trust these things to operate on their behalf?</strong></p><p><strong>Song: </strong><span>It’s viable in the sense that this is the future we’re heading toward. But of course, it is still early. There are many open challenges. There are lots of different parts of the technology and overall infrastructure that still need to be built. And we really need to develop new technologies to provide safer and more secure solutions in this new agentic Web.</span></p><p><span>We’re already developing those technologies. For example, our recent work on automatic end-to-end red teaming used multiagent teams to do red teaming on other agents. But we also need to develop new secure agent frameworks so that we can develop what we call secure-by-design ways of building these agents. W</span><span>e hope to bring the community together to develop these new security solutions to enable the agentic Web.</span></p>
