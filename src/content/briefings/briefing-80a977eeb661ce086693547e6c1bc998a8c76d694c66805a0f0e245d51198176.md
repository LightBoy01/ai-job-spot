<p>The task is to replicate the Math.pow() function, with the powers only integers.</p>

<p>The boilerplate code<br>
</p>

<div class="highlight js-code-highlight">
<pre class="highlight plaintext"><code>function pow(base, power){
  // your code here
}
</code></pre>

</div>



<p>If the power is 0, return 1<br>
</p>

<div class="highlight js-code-highlight">
<pre class="highlight plaintext"><code>if (power === 0) return 1
</code></pre>

</div>



<p>Multiply the base by the absolute value of the power, taking negative powers into consideration<br>
</p>

<div class="highlight js-code-highlight">
<pre class="highlight plaintext"><code>let result = 1;
let absPower = Math.abs(power);

 for (let i = 0; i &lt; absPower; i++) {
    result *= base;
  }
</code></pre>

</div>



<p>If the power is negative, return the reciporcal. Otherwise, return the result<br>
</p>

<div class="highlight js-code-highlight">
<pre class="highlight plaintext"><code>return power &gt; 0 ? result : 1 / result;
</code></pre>

</div>



<p>The final code<br>
</p>

<div class="highlight js-code-highlight">
<pre class="highlight plaintext"><code>function pow(base, power){
  // your code here
  if(power === 0) return 1;

  let result = 1;
  let absPower = Math.abs(power);

  for(let i = 0; i &lt; absPower; i++) {
    result *= base;
  }
  return power &gt; 0 ? result : 1 / result;
}
</code></pre>

</div>
