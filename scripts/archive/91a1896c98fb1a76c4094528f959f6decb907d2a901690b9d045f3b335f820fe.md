This is an exciting opportunity to join Manulife/John Hancock as a Lead AI Solution Engineer.

In this role, you will leverage your expertise in Azure AI Services, Azure PaaS services, FastAPI, and ReactJS, CosmoDB to build scalable, secure, and intelligent applications. You will lead projects or work streams independently, contributing to their planning and execution, and may act as a professional expertise resource for colleagues, advising on complex topics with authority.

This position is ideal for someone who thrives in a cloud-native environment and enjoys contributing to our mission by developing innovative solutions. You will be empowered to learn and grow your career in a supportive and inclusive environment, where well-being and inclusion are more than just words. As part of our global team, we’ll support you in shaping the future you want to see.

**Position Responsibilities:**

*   Translate business and functional requirements into documented technical specifications or user stories.
    
*   Design, develop, test, and deploy back-end functionality and components.
    
*   Write clear, readable, and maintainable code, taking ownership of the quality and usability of code.
    
*   Optimize back-end systems for performance and efficiency.
    
*   Integrate back-end systems with third-party applications through API development and data exchange.
    
*   Develop and maintain RESTful APIs and microservices.
    
*   Troubleshoot and resolve back-end system issues through database optimization and the implementation of efficient data structures and algorithms.
    
*   Document code and technical processes.
    
*   Uphold software development leading practices, including writing clean and extensive code.
    
*   Perform peer reviews of code/deliverables and analysis for continuous learning and continuous improvement.
    
*   Stay up-to-date with the latest back-end technologies and trends and continuously improve skills and competency.
    
*   Ensure data is properly stored and easily retrievable through the design and implementation of data models and the optimization of database performance.
    
*   Ensure the protection and authentication of sensitive data by implementing security mechanisms.
    
*   Design, develop, and maintain scalable backend services using Python and FastAPI.
    
*   Build and integrate RESTful APIs with Azure services and third-party platforms.
    
*   Develop and deploy applications using Azure Web Apps, Azure Functions, and Azure DevOps.
    
*   Implement CI/CD pipelines using Jenkins, Git, and other DevOps tools.
    
*   Secure applications using Azure AD, Key Vault, and Graph APIs.
    
*   Work with Cosmos DB, Azure OpenAI, and Azure AI Search to build intelligent, data-driven solutions.
    
*   Collaborate with front-end developers to integrate APIs with ReactJS applications.
    
*   Participate in code reviews, architecture discussions, and agile ceremonies.
    

**Required Qualifications:**

*   Strong experience with Azure PaaS services, including Web Apps, Functions, Key Vault, Cosmos DB, and Azure AI services.
    
*   Proficient in Python development, especially with FastAPI.
    
*   Solid understanding of REST API design and integration.
    
*   Experience with Azure Active Directory (Azure AD) and Microsoft Graph APIs.
    
*   Familiarity with CI/CD pipelines, Jenkins, and Git-based workflows.
    

*   Working knowledge of ReactJS and modern front-end development practices.
    
*   Experience deploying and managing applications in a cloud-native environment.
    

**Preferred Qualifications:**

*   Exposure to Azure OpenAI and AI Search for building intelligent applications.
    
*   Experience with containerization (Docker, Kubernetes) is a plus.
    
*   Familiarity with monitoring and logging tools in Azure.
