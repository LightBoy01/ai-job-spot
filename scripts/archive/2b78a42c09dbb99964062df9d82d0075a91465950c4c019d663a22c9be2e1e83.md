**Role Description** 

We are seeking a highly motivated and technically skilled Intern to join our team for the summer. This internship is ideal for students pursuing degrees in Data Analytics, Artificial Intelligence, Machine Learning, Computer Science, or related fields. You’ll work on real-world Analytics and AI applications, contribute to research and development, and help build scalable tools that support our mission to innovate through intelligent systems. 

**Job Responsibilities** 

Responsibilities include but are not limited to:  

*   Conduct quality assessments of data sets as well as issue spotting and trend outlier analysis.   
    

*   Analyze and clearly communicate data. Create front-end data visualizations that succinctly tell a story based on your data analysis. Present data informed conclusions to customers seeking answers. 
    

*   Collaborate with AI engineers and data scientists to design, train, and evaluate machine learning models for classification, prediction, and optimization tasks.  
    

*   Build and maintain data pipelines using Python and SQL for ingesting, cleaning, and transforming large datasets.  
    

*   Develop and deploy web-based dashboards and tools using React, Flask, Tableau, PowerBI and PostgreSQL to visualize model outputs and support decision-making.  
    

*   Assist in the development of deep learning models using PyTorch or TensorFlow for tasks such as image recognition, natural language processing, or game-state evaluation.  
    

*   Participate in weekly research meetings, code reviews, and technical design sessions.  
    

*   Document findings, write clean and maintainable code, and present results to cross-functional teams. 
    

*   Other duties and responsibilities as assigned. 
    

**Preferred Skills** 

*   SQL Proficiency with experience writing queries one or more of the following: Oracle, SQL Server, MySQL, PostgreSQL 
    

*   Linux/Unix Scripting experience 
    

*   Experience with statistical software (R, Python) a plus. 
    

*   Front end User Interface development skills, such as Java Script, Pearl, HTML, ASP 
    

*   ETL and Data cleaning. 
    

*   Preferred Majors: Data Analytics, Artificial Intelligence, Computer Science, Statistics.
