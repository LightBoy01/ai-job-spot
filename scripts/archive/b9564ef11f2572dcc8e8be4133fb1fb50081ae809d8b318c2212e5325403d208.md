Job Description & Summary A career within our Agentic AI team will provide the opportunity to design, develop, and implement end-to-end agentic AI solutions. You’ll work with various agentic frameworks, Retrieval-Augmented Generation (RAG), guardrail design, and full-stack implementations.

Responsibilities

\- Gather business requirements and translate them into agentic workflows. - Develop and orchestrate AI agents using LangChain/LangGraph/Google ADK/AutoGen. - Implement RAG pipelines and memory-augmented workflows. - Define structured data models with Pydantic. - Implement guardrails using JSON Schema, regex, LLM-as-judge. - Integrate APIs, enterprise apps, and MCP/A2A protocols. - Build dashboards and microservices (FastAPI, Python, ReactFlow). Manager: Own delivery roadmap, oversee multi-team orchestration, engage with senior stakeholders.

Mandatory Skill Sets

\- Strong Python & FastAPI development along with knowledge of well known libraries like Pandas, Pydantic etc. - Hands-on with agent frameworks (LangChain, LangGraph, AutoGen, Google ADK). - RAG design and implementation. - Guardrail techniques (JSON Schema, regex, LLM-as-judge). - CI/CD, containerization, cloud-native deployment.

Preferred Skill Sets

\- Knowledge of MCP server / A2A protocol. - Observability tooling (LangSmith, framework metrics). - Full-stack exposure (React, ReactFlow, Next Js, Node Js etc.). - Open-source contributions.
