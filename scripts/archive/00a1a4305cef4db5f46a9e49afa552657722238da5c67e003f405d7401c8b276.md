About Rockefeller Capital Management:

Rockefeller Capital Management was established in 2018 as a leading independent financial advisory services firm. Originally founded in 1882 as the family office of John D. Rockefeller, the Firm has evolved to offer strategic advice to ultra- and high-net-worth individuals and families, institutions, and corporations from offices in 30 markets throughout the United States, as well as an office in London. The Firm oversees $151 billion in client assets as of December 31, 2024.

Position:

As an Application Developer, you will be part of a collaborative development team focused on building secure, high-performance web applications in a Microsoft Azure environment. You will contribute to the design and delivery of intuitive user interfaces and data-rich dashboards that support our financial advisors and their teams in delivering exceptional client service. This role offers the opportunity to work across the full stack—leveraging TypeScript, Angular, and ASP.Net Core Web API—while partnering closely with product, design, data, and engineering teams to ship scalable, enterprise-grade solutions.

Responsibilities:

*   Develop responsive web applications using TypeScript, Angular, HTML, CSS, and ASP.Net Core Web API.
*   Build intuitive dashboards and user interfaces that streamline workflows for financial advisors.
*   Integrate front-end applications with Azure-hosted APIs and services (App Service, API Management, Azure Functions).
*   Write clean, testable code and participate in code reviews to maintain high-quality standards.
*   Contribute to shared UI libraries and enforce design and accessibility standards.
*   Instrument applications for telemetry and proactively troubleshoot performance and UX issues.
*   Collaborate with product, design, data, and engineering teams to scope, iterate, and deliver features.
*   Continuously improve application reliability and user experience across the stack.

Qualifications:

*   Bachelor’s degree in Computer Science or related field.
*   4–5 years of professional software development experience, preferably in a financial services environment.
*   Proficiency in TypeScript and Angular framework for front-end development.
*   Experience integrating with ASP.Net Core RESTful APIs and deploying on Microsoft Azure.
*   Familiarity with financial charting libraries such as High Charts or similar.
*   Solid understanding of testing, debugging, and performance optimization for web applications.
*   Experience with SQL Server development is a plus.
*   Bonus qualifications:
    *   Experience developing AI agents, chatbots, or co-pilot features.
    *   Familiarity with Azure AI services or OpenAI integrations.
    *   Knowledge of Azure platform offerings.
    *   Understanding of microservices architecture and containerization (Docker/Kubernetes).

Skills:

*   TypeScript, Angular, HTML, CSS
*   ASP.Net Core Web API development
*   Azure services: App Service, API Management, Azure Functions
*   Financial charting libraries (e.g., High Charts)
*   SQL Server (nice to have)
*   Clean coding practices and test-driven development
*   UI/UX design principles and accessibility standards
*   Performance optimization and telemetry instrumentation
*   Collaboration across product, design, and engineering teams
*   Familiarity with AI/ML integrations and microservices architecture
*   Containerization tools (Docker, Kubernetes)
