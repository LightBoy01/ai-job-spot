**Job Description:**
We’re seeking a motivated entry-level AI/ML Engineer to help build cutting-edge AI agents and machine learning solutions. This is an excellent opportunity for a recent graduate or early-career professional to gain hands-on experience with production AI systems, including RAG models, MCP endpoints, and anomaly detection, while working alongside experienced engineers.
**Key Responsibilities**
*   Develop and support RAG AI agents (LangSmith/LangGraph)
*   Deploy and maintain MCP servers (FastMCP on AWS ECS)
*   Contribute to anomaly detection and smart alarming models on Databricks
*   Write clean, maintainable Python code and participate in reviews
*   Collaborate with senior engineers on design and implementation
*   Document technical work, test, debug, and optimize models
*   Support data pipeline and preprocessing workflows
**Qualifications:**
*   Bachelor’s/Master’s in CS, Data Science, or related field (or equivalent experience)
*   Foundational ML knowledge and Python skills
*   Basic cloud experience (AWS preferred)
*   Familiarity with Git and strong problem-solving skills
*   Excellent communication and teamwork abilities
*   Able to work onsite in Philadelphia 3 days per week
**Preferred**
*   Exposure to LLM/RAG frameworks (LangChain, LangSmith)
*   Experience with Docker/ECS, Databricks, or MLOps practices
*   Familiarity with SQL, vector databases, or anomaly detection projects
