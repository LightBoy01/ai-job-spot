**About the Role**

We are seeking an experienced Azure Cloud Engineer to own our infrastructure and DevOps lifecycle. You'll play a critical role in designing, scaling, and securing our cloud-native architecture, which supports distributed microservices and AI-driven business automation workflows. If you're passionate about containerization, automation, and modern cloud networking, this role is for you. 

**Key Responsibilities** 

*   Design and manage Azure-native infrastructure to support a multi-tenant SaaS application 
*   Build and maintain containerized deployments (Kubernetes/AKS) 
*   Own CI/CD workflows (build, test, promote) across multiple environments 
*   Implement network-level security policies and service-to-service communication patterns 
*   Configure scalable, observable systems using modern monitoring/logging stacks 
*   Collaborate with engineers to optimize performance and scalability of distributed services 
*   Conduct performance tuning, cost optimization, and capacity planning across cloud resources and deployments 
*   Participate in architectural discussions, design reviews, and security assessments for cloud infrastructure 

**Required Skills** 

*   5+ years of experience in cloud engineering, DevOps, or infrastructure roles. 
*   Deep expertise with Microsoft Azure, including services like: 
*   Azure Kubernetes Service (AKS) 
*   Azure VNETs, Private Endpoints, and NSGs 
*   Azure Key Vault, Blob Storage, App Gateway 
*   Experience building CI/CD pipelines using GitHub Actions, Azure DevOps, or equivalent 
*   Strong grasp of containerization and orchestration with Docker and Kubernetes 
*   Proficiency in Infrastructure as Code: Terraform or Bicep 
*   Working knowledge of distributed tracing, monitoring, and alerting 
*   Experience designing secure, highly available, zero-trust cloud networks 
*   Optimize resource utilization and cost-efficiency across infrastructure environments 
*   Strong familiarity with managing secrets, identities, and service principals across Azure services 
*   Knowledge of networking, DNS, load balancing, and secure API exposure in Azure environments 

**Preferred Skills** 

*   Familiarity with zero-downtime deploy patterns (e.g., blue-green, canary) 
*   Scripting skills in Bash or Python for automation 
*   Microsoft certifications such as Azure Administrator Associate, DevOps Engineer Expert, or Solutions Architect Expert
