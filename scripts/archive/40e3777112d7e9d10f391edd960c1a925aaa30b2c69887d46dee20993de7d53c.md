**About the Role:**

We are seeking a Full Stack Software Engineer with a strong focus on **backend** systems to help modernize and evolve our platforms. This role is ideal for engineers who are excited to take on complex backend challenges, from transitioning legacy Spring MVC applications into Spring Boot microservices, to designing scalable event-driven systems powered by Redis, RabbitMQ, and cloud-native architectures. Additionally, leveraging AI-powered tools and frameworks will be crucial in optimizing development processes, automating tasks, and enhancing software capabilities.

**We are looking for someone who has:**

*   A bachelor's degree in Computer Science, Engineering, or a related field.
*   A minimum of 5+ years of experience in software development and architecture, with a deep understanding of building and deploying applications with cutting-edge technologies & AI tools.
*   Deep expertise in Java and the Spring ecosystem (Spring Boot, Spring Data, Spring Security).
*   Hands-on experience with Redis and message brokers such as RabbitMQ, Kafka, or similar.
*   Familiarity with AWS cloud services (ECS, EC2, ECR, RDS, S3).
*   Experience in integrating and leveraging AI-driven development tools to enhance efficiency, such as GitHub Copilot, OpenAI APIs, TensorFlow, Cursor or other machine learning frameworks.
*   Strong focus on producing clear technical documentation (system designs, API contracts, operational guides).
*   A passion for problem-solving and continuous improvement of applications.

**Key skills needed to be successful in the role:**

*   Expertise in Java and Spring Boot for building scalable, reliable backend services.
*   Practical experience with Redis (caching, pub/sub) and messaging systems (RabbitMQ or equivalents).
*   Proficiency with relational databases (SQL) and NoSQL databases (MongoDB).
*   Deployment and orchestration using Docker and Kubernetes.
*   Cloud infrastructure knowledge, especially with AWS ECS, EC2, and ECR.
*   Familiarity with RESTful APIs and microservices architecture.
*   Experience with AI-assisted coding tools and machine learning APIs. 

**You may be a good fit if you have these additional skills and/or educational background:**

*   Experience with Kafka or other streaming platforms.
*   Knowledge of observability and monitoring tools (Prometheus, Grafana, ELK).
*   Experience with JavaScript programming and proficiency in related technologies (ReactJS, TypeScript, NodeJS). Exposure to NestJS is a plus.
*   Experience with AI/ML tools and frameworks, including OpenAI APIs, TensorFlow, PyTorch, or similar platforms.
*   Understanding of mobile app development or mobile-responsive web design.
*   Relevant certifications in TypeScript, APIs, AI/ML technologies, and related fields.
