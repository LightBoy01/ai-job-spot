**Job Description**

**What is the opportunity?**

We are looking for a top-notch, driven, Full stack Developer who is a great team player and passionate about the quality of their code. As a Full stack Developer, you will be contributing to the technical delivery of your team, and delivering high quality, scalable solutions. You will have the opportunity to learn new technologies and help shape new code development/management and process workflows that are currently being implemented. This role requires someone who can roll up their sleeves in developing their future career opportunities.

**What will you do?**

*   This position will be focused on Vue and other front-end technologies, Java, Spring/Spring Boot, micro services, nodejs, API development for US-Wealth Management.
*   Code reviews, code merging and branching methodologies using Git and code release process.
*   Develop, code, document and execute unit, system, integration and acceptance tests using different languages and testing tools for functions of high complexity.
*   Automate processes within the development pipeline; identify opportunities for efficiency gains and reducing time-to-market and enabling continuous delivery.

**What do you need to succeed?**

**Must-have**

*   B.S. degree in Computer Science or related technical field (e.g. EE, physics or mathematics), or equivalent practical experience.
*   2+ years in Front-end technologies such as, Vue.js, React.js, Angular 14+, rxjs, ngrx, and testing frameworks such as: Jest, Jasmine, Cypress
*   2+ years in the Java stack, having experience in Java 17+, Node.js, REST API/Micro services, Maven, SQL, Springboot 2+.
*   Experience with automation and testing frameworks, namely, JUnit, Wiremock, Mockito and other emerging frameworks.
*   Development, testing and troubleshooting of large scale online and batch applications as well as RESTful API and interface specifications (Swagger, OpenAPI, SOAP).
*   Experience in the Devops space – Helios, Scanning Tools (AquaScan, Snyk, SonarCube)
*   Knowledge of Kafka, MySQL, Non-relational databases, Caching.
*   Experience with automation and working with AI Prompt Engineering and Gen AI.

**Nice-to-have**

*   GraphQL
*   Redis caching
*   Python
*   RUST
