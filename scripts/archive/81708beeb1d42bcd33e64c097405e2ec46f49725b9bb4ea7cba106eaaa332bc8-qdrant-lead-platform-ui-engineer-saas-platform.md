### Description\nQdrant is a cutting-edge technology company specializing in open-source vector databases designed for next-generation AI applications. Our platform enables high-performance vector similarity search, allowing businesses to unlock deep insights from unstructured data. By offering both open-source software and managed cloud solutions, we empower developers and enterprises to build scalable, AI-driven search and recommendation systems with ease.\n\nAs we grow, we are looking for a **Lead Platform UI Engineer** to take ownership of our frontend platform and UI architecture. In this role, you will drive the design and evolution of our shared UI foundations (design system, reusable components, patterns, tooling) across Qdrant Cloud, and work side-by-side with our backend team to build a robust, scalable developer and customer experience. As a Lead Platform UI Engineer with a strong frontend focus and full-stack mindset, you will own the front-of-house experience of Qdrant Cloud as well as the UI platform used by multiple product teams.\n\n### Responsibilities\n- **Define and evolve the UI platform:**\n    - Design and own our frontend architecture for Qdrant Cloud, focusing on modularity, scalability, and performance.\n    - Build and maintain a shared component library / design system in React + TypeScript to be reused across teams and products.\n    - Establish standards for state management, routing, API integration, error handling, and observability in the frontend.\n- **Hands-on frontend development:**\n    - Implement complex, high-impact features in React (with modern tooling such as TanStack, OpenAPI, TypeScript, etc.).\n    - Ship well-structured, testable modules and improve the overall DX (developer experience) of our frontend stack.\n    - Continuously profile and tune frontend performance, bundle size, and runtime behavior.\n- **Cross-functional collaboration & backend integration:**\n    - Work closely with backend engineers to shape and optimize APIs, contracts, and data flows for UI needs.\n    - Contribute to Python backend services when necessary to unlock or improve frontend functionality.\n    - Collaborate with Product and Design to turn requirements and UX flows into robust, maintainable implementations.\n- **Technical leadership & mentorship:**\n    - Act as the go-to person for frontend and UI platform topics across teams.\n    - Mentor other frontend developers, review critical pull requests, and help establish and enforce coding standards and best practices.\n    - Drive technical decision-making around frontend architecture, libraries, and tooling.\n- **Infrastructure, quality & reliability:**\n    - Own key parts of the frontend delivery pipeline: CI/CD, linting, testing, quality gates, error tracking, performance monitoring.\n    - Help define and maintain quality metrics (e.g. core web vitals, error budgets, coverage, build times).\n    - Ensure our UI stack is secure, observable, and resilient by default.\n\n### Qualifications\n- 5+ years of experience in frontend development, with substantial experience owning or co-owning a production React application.\n- Deep expertise in React, JavaScript/TypeScript, HTML5, and CSS3, including component composition, hooks, and modern patterns.\n- Solid understanding of web platform fundamentals: JavaScript, DOM, REST APIs, HTTP/HTTP2, caching, browser performance.\n- Experience with backend technologies (ideally Python or Node.js) and single-page applications (or hybrid architectures).\n- Proven track record designing or contributing to frontend architectures, shared component libraries, or design systems.\n- Strong familiarity with the frontend ecosystem: testing, linting, bundling, error tracking, performance profiling, CI/CD pipelines.\n- Comfortable debugging frontend–backend interactions, API contracts, and performance issues in production.\n- Excellent communication skills and ability to collaborate with engineers, product managers, and designers.\n- Experience providing technical leadership or mentoring to other engineers, even if not in a formal manager role.\n- **Nice to Have:**\n    - Familiarity with Python frameworks like Flask or FastAPI.\n    - Familiarity with meta frameworks like Remix, Next.js, and/or libraries like TanStack Router and Query.\n    - Experience with modular, scalable frontend architectures.\n    - Knowledge of OAS, GraphQL and/or WebSockets.\n    - Prior experience working in a SaaS or startup-like environment.\n\n### Author's Take\nThis is a high-impact \"Lead\" role for a seasoned Frontend Engineer passionate about building scalable UI platforms and contributing to the core of AI infrastructure. You'll have significant ownership over the frontend architecture and design system for Qdrant Cloud, working in a fully remote, collaborative, and innovation-driven environment. This opportunity is ideal for someone who thrives on technical leadership, mentorship, and wants to shape the future of AI technology in an open-source context. The emphasis on both hands-on development and strategic platform evolution makes this a truly compelling position.
