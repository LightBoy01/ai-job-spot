Job Title:

.NET Developer (AI-Integrated Systems)

Job Description

We’re building next-gen agentic systems that blend LLMs, APIs, and real-time data to create intelligent, adaptive solutions. Our platform powers custom AI agents and assistants, and we’re looking for .NET Developers to help us bring these systems to life through scalable, cloud-ready backend infrastructure.

**What You’ll Do**

*   Design and build robust backend services using .NET technologies.
*   Integrate and manage data across **SQL Server**, **MongoDB**, and **DynamoDB**.
*   Work with **AWS services** like Lambda and S3 to build serverless workflows.
*   Collaborate with NLP engineers and AI teams to integrate **OpenAI** and **Azure OpenAI** capabilities.
*   Contribute to REST API development, backend logic, and data pipelines.
*   Participate in Agile/Scrum practices — sprints, standups, reviews.
*   Occasionally interface with Python and Node.js components (no deep coding required).
*   Help shape backend architecture and integration patterns for our AI-first products.

**Tech Stack You’ll Work With**

*   .NET
*   SQL Server, MongoDB, DynamoDB
*   AWS (Lambda, S3, etc.)
*   OpenAI / Azure OpenAI
*   Python & Node.js (for integration)
*   REST APIs, microservices, serverless patterns

**Requirements**

*   Bachelor’s or Master’s degree in Computer Science, Linguistics, Data Science, or a related field.
*   Strong experience in backend development using .NET technologies.
*   Comfortable working with both relational and NoSQL databases.
*   Experience integrating third-party APIs and cloud services.
*   Familiarity with AWS or other cloud platforms.
*   Collaborative mindset — you’re a team player and communicate well.
*   Comfortable working in Agile/Scrum environments.
*   Exposure to OpenAI, Azure OpenAI, or similar LLM APIs.

**Nice to Have**

*   Experience with serverless architecture and event-driven systems.
*   Some familiarity with Python or Node.js environments.

**Why Join Us?**

*   Be part of a cutting-edge AI product team that values innovation and execution.
*   Work on exciting projects at the intersection of backend engineering and AI.
*   Collaborate with friendly, talented teammates in a fast-moving environment.
*   Help shape the future of how intelligent systems are built and deployed.

**Qualifications**:

*   Bachelor's degree in Computer Science, Engineering, or a related field.
*   10+ years of experience in .NET development, with a strong focus on C# and ASP.NET.
*   Proven experience in designing and implementing complex software solutions.
*   Strong understanding of object-oriented programming and design patterns.
*   Experience with front-end technologies such as HTML, CSS, JavaScript, and frameworks like Angular or React.
*   Proficiency in database design and development using SQL Server or other relational databases.
*   Excellent problem-solving skills and attention to detail.
*   Strong communication and leadership skills, with the ability to work effectively in a team environment.
*   Experience with cloud platforms such as Azure or GCP.
