Be able to apply GenAI models as part of the solution. Could also include but not limited to deep learning, neural networks, chatbots, image processing.

**Good to have skills :** NA

Summary Are you an experienced software engineer looking to drive the technical direction of market leading (#1) software products. Join us to help develop our Returns product suite leveraging AI The ideal candidate has full-stack expertise in development, design, testing, and operations, with experience in scalable Cloud Native SaaS solutions. Platform experience is a plus. Roles and Responsibilities : Development: Design, code (hands-on), and maintain (proactive monitoring, troubleshooting) software solutions using object-oriented or modern languages (C#, Java, Go etc.) AI Execution: Execute on the mission of AI integration across our product suite, including Generative AI, NLP, and predictive analytics. Test: Create test scenarios and design, develop, and execute corresponding automated tests. Cloud Infrastructure: Experience with major cloud providers like AWS, Azure or GCP. Understanding of Infrastructure as Code (e.g. Terraform, CloudFormation, Helm etc.) Collaboration: Excel in global cross-functional teams, including product management and architecture. Code Reviews: Utilize code reviews to ensure code quality, performance and maintainability, as well as mentoring opportunities. Continuous Improvement: Champion a culture of continuous improvement by driving engineering excellence, conducting root cause analyses, and implementing feedback loops to enhance code quality, team productivity, and system reliability. Technical experience and Professional attributes: Experience in object-oriented/modern languages (C#, Java, Go etc.) Understanding of software design patterns Good understanding of RESTful API, Open API design and development, and database technologies (RDBMS, NoSQL).  Working experience with CI/CD pipelines, containerization (Docker, Kubernetes) and infrastructure as code (Terraform, CloudFormation, etc.). Hands-on experience with event driven architecture (e.g., Kafka, Pulsar, SNS/SQS). Experience in designing and implementing scalable test automation strategies using modern frameworks and tools such as Playwright, Cypress, Selenium, TestNG etc., with integration into CI/CD pipelines (e.g., GitHub Actions, Azure DevOps, Jenkins) and cloud-based testing platforms. Experience with front-end technologies (e.g. React, Angular) is a strong plus. Basic experience designing and delivering AI solutions using modern software engineering practices and cloud technologies (e.g., Azure, AWS, GCP), with a focus on Generative AI and Large Language Models (LLMs) is a plus. Basic understanding of security best practices and frameworks. Knowledge of Snyk is a plus. Demonstrated problem-solving skills for complex tech challenges. Excellent communication, interpersonal, presentation, and facilitation skills across time zones. Experience working on AI/ML initiatives or certifications in AI technologies is a strong plus. Educational Qualifications : Education: Master’s degree (preferred) or bachelor’s degree in computer science, engineering, or a related field (or equivalent experience).
