### Description\\nTaleroo is a modern learning & talent platform built on a full-stack environment using **Next.js**, **Python/Flask**, and **PostgreSQL**. We manage complex user flows, AI-powered recommendations, and dynamic dashboards. We are seeking a **QA Engineering Intern** who is serious about automated testing, software quality, and modern CI/CD workflows to elevate our quality assurance processes to the next level.\\n\\n### Responsibilities\\n- Build automated frontend tests for our Next.js application (Playwright or Cypress)\\n- Write backend API tests for our Flask services using PyTest\\n- Validate PostgreSQL models, SQLAlchemy queries, and migration flows\\n- Develop regression test suites that cover core user journeys\\n- Integrate test suites into GitHub Actions and help improve CI/CD pipelines\\n- Reproduce, document, and prioritize bugs together with the engineering team\\n- Write clear documentation for test cases, processes, and QA guidelines\\n\\n### Qualifications\\n- Understanding of web system architecture (frontend + backend + database)\\n- Some experience with Next.js/React, Python/Flask, and relational databases\\n- Basic familiarity with testing frameworks (Playwright, Cypress, Selenium, PyTest)\\n- Comfortable writing tests in both JavaScript and Python\\n- Structured, detail-oriented mindset and a willingness to intentionally break things to improve stability\\n- **Bonus**: experience testing AI features, data pipelines, or MLOps flows\\n\\n### Author's Take\\nThis is an exceptional entry-level opportunity for a motivated QA Engineering Intern to gain hands-on, full-stack experience in a real production environment. With direct mentorship from experienced engineers, exposure to modern technologies like Next.js, Flask, PostgreSQL, and AI-driven features, and a flexible remote schedule, your work will directly impact product stability and accelerate release cycles. If you're passionate about shaping QA processes and building robust testing infrastructure, Taleroo offers a collaborative and impactful start to your career where your contributions are genuinely valued.
