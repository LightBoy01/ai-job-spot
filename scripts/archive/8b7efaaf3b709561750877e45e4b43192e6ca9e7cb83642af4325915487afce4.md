**Job Description**

DUTIES:                               Contribute to a team responsible for creating tables using SQL within Teradata database; perform object-oriented software development using Python; process big data with Apache Spark; schedule data load jobs using Airflow; perform big data Extract, Transform, and Load (ETL) using Databricks and Kubernetes; store data within cloud platforms, including AWS S3, and on-premise platforms, including MinIO; execute data integration and consolidation projects; contribute to low-level design and test planning; develop and perform unit testing on integration modules; develop large, scalable, and repeatable ETL pipelines to ingest data from various source systems; analyze, profile, and understand the source data and proactively generate suggestions to improve the design or handling of data and technical challenges during project execution; and identify and recommend framework changes to increase performance and scalability. Position is eligible for 100% remote work.

REQUIREMENTS:             Bachelor’s degree, or foreign equivalent, in Computer Science, Engineering, or related technical field, and one (1) year of experience creating tables using SQL or a relational database; performing object-oriented software development using Python; processing big data with Apache Spark; scheduling data load jobs using Airflow; performing big data Extract, Transform, and Load (ETL) using Databricks and Kubernetes; and storing data within cloud platforms, including AWS S3, and on-premise platforms, including MinIO.
