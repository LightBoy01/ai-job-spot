Job Summary We are seeking a skilled and experienced Cloud Engineer to support a secure and scalable cloud infrastructure for a Singapore Government-appointed agency operating on commercial cloud platforms. This Subject Matter Expert (SME) role requires real-world experience in managing multi-service cloud environments using AWS, strong Infrastructure-as-Code (IaC) capabilities, lifecycle and patching operations, and proactive operational support. The ideal candidate will be hands-on, security-aware, automation-driven, and familiar with strict uptime, compliance, and audit requirements. Key Responsibilities Cloud Infrastructure Operations • Operate and maintain AWS-native services in production, including Lambda, ECS, EKS, FSx, Redshift, Glue, Neptune, SES, GuardDuty, WAF, Shield Advanced, Security Hub, KMS, Secret Manager, SNS, SQS, EventBridge, SageMaker, API Gateway. • Ensure uptime, availability, and secure operations. • Monitor infrastructure, manage alerts, and support production incidents. Infrastructure as Code (IaC) • Design and maintain infrastructure deployment pipelines using Terraform, CloudFormation, and Ansible. • Troubleshoot environment drift and pipeline failures. • Promote automation in cloud operations. OS Lifecycle & Patch Management • Manage patching across RHEL (v8→v9) and Windows Server (2016→2025) using AWS Patch Manager, WSUS, and YUM/DNF. • Schedule, automate, and track patches. • Coordinate approvals and ensure compliance. SSL and EOL Management • Track SSL certificate renewals across environments. • Identify and remediate EOL components like OS versions and Lambda runtimes. Tool Integration & Interoperability • Integrate tools like NGINX and input into the observability stack. • Work with SRE teams to enhance infrastructure monitoring. Documentation & Reporting • Maintain infrastructure runbooks, patch/change logs, post-mortem reports, and audit artifacts. Soft Skills & Competencies • Problem Solving – Troubleshooting complex systems • Communication – Clear with technical and non-technical teams • Collaboration – Cross-functional teamwork • Adaptability – Responsive in changing environments • Accountability – Takes ownership of outcomes • Attention to Detail – Accurate and secure implementations • Customer Focus – Supportive and service-oriented • Time Management – Prioritizes critical tasks effectively • Continuous Learning – Keeps up with cloud and security practices • Resilience – Performs under pressure and in incidents SME Expectations – Role Behavior This Subject Matter Expert (SME) role requires: • Proficiency across AWS services and architecture. • Experience in uptime-critical and compliant environments. • Mentorship capabilities for junior engineers. • Initiative and proactive incident prevention. • Calm and structured incident handling. • Adherence to change and incident processes. • Audit-readiness and documentation discipline. Technical Skills & Experience Area Skills Required Cloud Hands-on with AWS services in production IaC Terraform, CloudFormation, Ansible OS RHEL & Windows Server administration Patching AWS Patch Manager, WSUS, YUM/DNF SSL/EOL Managed certs and lifecycle remediation Documentation Runbooks, change logs, compliance docs Required Qualifications • Bachelor’s degree in computer science, Information Systems, or a related field • Minimum 6 years’ experience in DevOps / SRE roles, with at least 4 years on public sector or regulated Cloud environment • AWS Certified Solutions Architect • RHCE or Microsoft Server Admin • ITIL v4 Foundation (preferred)
