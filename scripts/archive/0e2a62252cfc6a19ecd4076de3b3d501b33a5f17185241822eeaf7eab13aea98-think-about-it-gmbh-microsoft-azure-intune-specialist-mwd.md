### Description

Join the think Group at our Bochum location as a Microsoft Azure / Intune Specialist (m/w/d) and become a pivotal part of our team. This role invites you to design, implement, and operate cutting-edge Microsoft Azure and Microsoft Intune solutions for our diverse client base. You will be instrumental in modernizing cloud infrastructures, managing mobile devices, and ensuring robust security and identity management within the dynamic Microsoft cloud ecosystem.

### Responsibilities

*   Plan, implement, and operate Microsoft Azure and Microsoft Intune solutions for our customers.
*   Consult on and implement M365 services, Azure AD, Conditional Access, Autopilot, Endpoint Manager, and other related technologies.
*   Administer and optimize cloud infrastructures in Azure (IaaS/PaaS), including networks, storage, security, and identity management.
*   Integrate and manage mobile devices (MDM/MAM) using Microsoft Intune.
*   Conduct cloud migrations, including analysis, conceptualization, and active support during implementation.
*   Create comprehensive technical documentation and concepts.
*   Provide 2nd-level support and troubleshooting for complex Microsoft Cloud inquiries.

### Qualifications

*   Completed technical degree or comparable vocational training (e.g., IT specialist for system integration).
*   Profound knowledge in the Microsoft Cloud environment, particularly Azure, Microsoft Intune, Azure AD, and Microsoft 365.
*   Demonstrated experience in implementing Endpoint Management strategies with Intune and Autopilot.
*   Knowledge of Azure networking services, security, monitoring, and identity management.
*   Good PowerShell skills for automation and script creation.
*   A solution-oriented approach, strong team spirit, and pronounced customer orientation.
*   Excellent German and English language skills, both written and spoken.
