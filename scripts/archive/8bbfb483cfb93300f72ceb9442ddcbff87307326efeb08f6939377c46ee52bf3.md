**Job Summary:**

We are seeking an experienced **Senior Network Administrator** to join our IT team. The successful candidate will be responsible for designing, implementing, and managing our network infrastructure, with a focus on Palo Alto and Azure firewalls, Cisco switches, Meraki wireless access points (WAPs), and F5 load balancers. The role requires a strong working knowledge of cybersecurity best practices and IT Service Management (ITSM) processes to ensure secure, reliable, and efficient network operations.

**Job Responsibilities:**

**A. Network Security Infrastructure Management:**

*   Configure, manage, and troubleshoot F5 BIG-IP LTM load balancers to ensure high availability, scalability, and performance of web applications.
    
*   Administer and optimize network security policies and configurations on Palo Alto firewalls, ensuring robust protection against external and internal threats.
    
*   Oversee Microsoft Azure cloud networking solutions, including deployment and management of virtual appliances, to ensure secure cloud connectivity.
    
*   Configure, manage, and troubleshoot Cisco devices including Nexus core switches, ensuring optimal network performance, redundancy, and security.
    
*   Administer and configure wireless access points from various vendors (e.g., Cisco Meraki, Aruba, ) to maintain a secure, efficient, and high-performance wireless network environment.
    
*   Help develop and enforce firewall policies to protect against unauthorized access, malware, and other threats, including URL filtering, application control, and threat prevention on Palo Alto devices.
    
*   Implement cybersecurity measures as mandated by security team such as intrusion detection/prevention systems (IDS/IPS), secure VPN tunnels, and multi-factor authentication for network access.
    
*   Conduct regular security audits and vulnerability assessments to identify and mitigate risks.
    
*   Create and update detailed network diagrams to accurately reflect the current state of both physical and logical network topologies
    

**B. Network Monitoring & Reporting:**

*   Continuously monitor network traffic and security events, leveraging available tools to detect and mitigate potential threats.
    
*   Generate reports on network performance, security incidents, and compliance metrics for management review.
    
*   Deploy and manage network monitoring tools (e.g., DataDog) to track performance metrics, bandwidth usage, and potential security incidents.
    
*   Analyze traffic patterns and logs to identify bottlenecks, packet loss, or suspicious activity.
    
*   Fine-tune configurations (e.g., F5 load balancing algorithms, Cisco switch QoS settings, Meraki RF profiles) to optimize performance and user experience.
    

**C. ITSM Processes:**

*   Adhere to ITIL-based ITSM processes for incident, problem, and change management, using tools like JIRA.
    
*   Log and resolve network-related incidents, ensuring timely communication and resolution per service level agreements (SLAs).
    
*   Submit and manage change requests for network configuration updates, ensuring minimal disruption and proper documentation.
    
*   Contribute to problem management by identifying recurring issues and implementing long-term solutions.
    

**D. Documentation and Reporting:**

*   Maintain up-to-date documentation of network configurations, topologies, IP schemas, and security policies.
    
*   Create and update network diagrams using tools like Visio or Lucidchart.
    
*   Generate regular reports on network performance, security incidents, and capacity planning for management and compliance purposes.
    
*   Document troubleshooting steps and resolutions for knowledge base and future reference.
    

**E. Collaboration:**

*   Work with cybersecurity teams to align network configurations with security policies and respond to threats.
    
*   Partner with systems administrators to ensure seamless integration between network and server environments.
    
*   Collaborate with application teams to support specific network requirements (e.g., low-latency for VoIP or high-throughput for data transfers).
    
*   Participate in cross-functional projects, such as cloud migrations or data center expansions.
    

**F. Upgrades and Maintenance:**

*   Plan and execute firmware and software upgrades for Palo Alto firewalls, Cisco switches, Meraki WAPs, and F5 devices to ensure systems are up-to-date and secure.
    
*   Schedule and perform routine maintenance tasks, such as replacing failed hardware or updating configurations, during maintenance windows to minimize impact.
    
*   Test and validate upgrades in a lab environment before production deployment to ensure compatibility and stability.
    

These responsibilities ensure the Senior Network Administrator maintains a secure, reliable, and efficient network environment while adhering to cybersecurity best practices and ITSM standards.
