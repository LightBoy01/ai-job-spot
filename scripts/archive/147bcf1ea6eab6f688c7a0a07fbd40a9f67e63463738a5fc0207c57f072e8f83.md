**Are you excited to work with innovative security products?**
**Do solving some of the Internet's most difficult security challenges interest you?**
**Join our Application Security Incubation Team**
We operate like a startup within a larger security org, developing innovative solutions to protect modern applications from evolving threats. Our team combines expertise in security research, engineering, data science, and DevOps to undertake challenges in AI security, web security, data protection, and threat detection. Leveraging large-scale data and advanced technologies, we proactively identify and mitigate risks to ensure secure application deployment.
**Partner with the best!**
You will design and develop scalable backend services using microservices, distributed systems, and AI security. Collaborate with engineers, data scientists, and security experts, to build innovative security solutions for AI and traditional applications.
As a Backend Software Engineer, you will:
*   Designing and optimizing backend systems that support high-performance, secure, and resilient applications at scale.
*   Building real-time pipelines and analytics frameworks that enable data-driven decision-making and personalized experiences.
*   Implementing robust protections against modern threats, such as adversarial attacks and data leaks, while maintaining solid privacy guarantees.
*   Leveraging distributed systems, microservices, and AI/ML techniques to drive innovation across security and recommendation domains.
*   Working closely with engineers, data scientists, product managers, and security experts to develop impactful, user-centric solutions.
**Do what you love**
To be successful in this role you will:
*   Have 3+ years of experience in backend development with a deep foundation in Golang, Python and SQL.
*   Have experience with distributed systems, cloud architectures, microservices, and databases.
*   Have excellent problem-solving skills and the ability to work in a ever-changing, security-focused environment.
*   Have hands-on experience with Kubernetes, Docker, and containerized environments.
*   Have knowledge of real-time data processing and event-driven architectures (NATS, Kafka, gRPC, etc.).
*   Be proficient in cloud platforms like AWS, GCP, or Azure.
*   Be familiar with AI/ML security concepts, adversarial threats, and API security.
