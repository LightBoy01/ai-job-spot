**Role/Responsibilities**:

· Own one or more technical projects related to controls software engineering from idea to completion

· Apply concepts from coursework to drive creative solutions to complex problems

· Create a CI/CD pipeline component that uses AI to scan C++ source code and automatically generate or update technical documentation

· Build and integrate solutions that help our C++ developers write, test, debug, and document code more efficiently

· Design and develop a stand-alone, internal-facing AI/ML-powered web application
