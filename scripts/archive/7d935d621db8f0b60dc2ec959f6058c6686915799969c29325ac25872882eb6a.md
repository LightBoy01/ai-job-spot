**Job Details:**

Job Description:
-----------------
We are seeking a highly skilled and motivated CAD Software Engineer to join Intel’s next-gen AI chip group. In this role, you will develop and maintain automation infrastructure and tooling that supports our AI SoC silicon development teams.
Your work will enable scalable, efficient, and high-quality silicon design by leveraging advanced Python software development within modern EDA workflows.
This is an excellent opportunity for someone with deep expertise in Python and a passion for building scalable solutions for complex chip design challenges.
Key Responsibilities:
• Design, develop, and maintain Python-based tools and infrastructure to automate and streamline EDA workflows.
• Develop and extend GitHub Actions/Workflows to support continuous integration, validation, and deployment for hardware design flows.
• Partner with design and CAD teams to identify inefficiencies and deliver high-impact automation solutions.
• Integrate and support EDA tools from major vendors (e.g., Synopsys, Cadence, Siemens) into design flows.
**Qualifications:**
-------------------
• BS/MS in Computer Science, Electrical Engineering, or related field.
• 5+ years of experience in software development using Python.
• Experience using Git for source control in large collaborative environments.
• Experience using GitHub workflows, including GitHub Actions, secrets, runners, and CI/CD pipelines.
• Strong debugging and problem-solving skills with attention to software robustness and maintainability.
Preferred Qualifications:
• Familiarity with industry-standard EDA tools and front-end design workflows, including RTL development, simulation, functional verification, linting, and logic synthesis.
• Experience using GitHub SDK/API for automation and repository management.
• Familiarity with build systems (e.g., Make, CMake, Gradle) and dependency management.
• Exposure to front-end EDA data formats such as Liberty timing models, SDC constraints, and simulation data formats like SDF and VCD/FSDB.
• Experience designing, deploying, and managing containerized workloads using technologies such as Docker and Kubernetes.
This position is expected to change location in the near future to the Petah Tikva campus
