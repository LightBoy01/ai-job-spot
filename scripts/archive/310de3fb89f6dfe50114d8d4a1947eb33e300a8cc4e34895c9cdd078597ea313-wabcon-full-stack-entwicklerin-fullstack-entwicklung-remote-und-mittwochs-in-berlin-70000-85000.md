### Description

At our client, you will work where important decisions are made that drive Germany forward. As a Fullstack Developer, you will shape IT systems that make central administrative processes more modern, secure, and efficient – from the user interface to the database. Our client offers you responsible tasks, modern working conditions, diverse development opportunities, and a dedicated team shaping the digital future.

Apply now – and work on projects that truly matter!

### Responsibilities

*   Frontend and Backend development
*   Design and implementation of APIs (REST, GraphQL)
*   Conducting code reviews and automated tests
*   Independent implementation of user stories in development sprints
*   Identifying refactorings and other code optimizations (Frontend and Backend)
*   Independently identifying and introducing new tasks for the further development and improvement of the application
*   Independent and guided familiarization with extremely complex and extensive domain knowledge of the federal budget
*   Continuous further education in domain and technology and contributing this knowledge to the project

### Qualifications

*   Profound knowledge in Frontend development (Vue/Vuetify, React, JavaScript, TypeScript, HTML, CSS)
*   Profound knowledge in Backend development (Node.js, GraphQL, Java, Spring)
*   Good knowledge in PostgreSQL
*   Experience with testing frameworks (e.g., Jest, Vitest, Robot Framework, JUnit)
*   Basic understanding of software architecture
*   Proficient in Clean Code principles
*   Very good German language skills

_As part of the application process, candidates are asked to self-assess their proficiency (1=weakest, 10=strongest) in: Vue, Vuetify, React, JavaScript, TypeScript, HTML, CSS, NodeJS, SQL, Kubernetes, OpenShift, German._
