Wir wachsen weiter!  
Für unsere Cloud- und Data-Engineering-Projekte bei ADEAL Systems GmbH  
suchen wir einen erfahrenen DevOps Engineer (m/w/d), der moderne  
Technologien, Automatisierung und saubere Cloud-Architekturen liebt.

Aufgaben
--------

*   Aufbau, Automatisierung und Betrieb von Cloud-Infrastrukturen
*   Entwicklung und Pflege von CI/CD-Pipelines
*   Infrastructure as Code
*   Zusammenarbeit in einem kleinen, erfahrenen Engineering-Team
*   Projekte mit Fokus auf Cloud, Data, Security und Automatisierung

Qualifikation
-------------

**Dein Tech-Stack bei uns**

*   Cloud: AWS, Azure, Oracle OCI
*   Container: Docker, Kubernetes
*   IaC: Terraform, CloudFormation
*   Linux / Bash / Shell-Scripting
*   Netzwerk & Security (IAM, VPC, Firewalls)
*   Data Engineering (nice to have): Python, PySpark

**Dein Profil**

*   Abgeschlossenes Studium in Informatik, Wirtschaftsinformatik oder vergleichbare Qualifikation
*   Mehrjährige praktische Erfahrung im DevOps- oder Cloud-Umfeld
*   Sicherer Umgang mit AWS; Azure oder OCI von Vorteil
*   Fundierte Kenntnisse in Docker & Kubernetes
*   Erfahrung mit Terraform oder/oder CloudFormation
*   Linux-Know-how und Routine im Bash-/Shell-Scripting
*   Grundlegendes Verständnis von Netzwerk- und Security-Konzepten
*   Bonus: Erfahrungen im Data Engineering (Python/PySpark)
