**About our group:**
--------------------

Join the Test Process & Firmware Engineering (TPFE) team at Seagate Singapore, where we are pioneering the development of an internal AI assistant to support firmware engineers. This assistant will be trained specifically on Seagate’s proprietary CERT codebase to enhance productivity, reduce debugging time, and streamline code development workflows.

**About the role - you will:**
------------------------------

As an intern, you will contribute to the design and development of an AI-powered assistant tailored to Seagate’s HDD test firmware domain. This assistant will enable engineers to search, understand, and reason over proprietary code, refactor existing modules, write new code, and generate self-tests—all aligned with Seagate’s internal coding practices and compliance policies.

**About you:**
--------------

*   Assist in building and refining the AI assistant’s capabilities to understand Seagate’s proprietary C and Python codebase (CERT domain – SF3 and PF3).
*   Develop tools and interfaces that allow engineers to query the codebase in natural language and receive context-aware suggestions.
*   Implement features for semantic code search, code generation, refactoring, and automated self-test creation.
*   Ensure the assistant adheres to Seagate’s internal coding standards, naming conventions, and project-specific structures.
*   Collaborate with firmware engineers to gather feedback and iterate on assistant functionality.
*   Work with IT and AI governance teams to ensure compliance with Seagate’s data protection and AI usage policies.

**Your experience includes:**
-----------------------------

*   Strong programming skills in Python and C/C++.
*   Familiarity with software development tools (e.g., Git, IDEs like SlickEdit).
*   Understanding of firmware development and test processes is a plus.
*   Interest in AI/ML technologies and natural language processing.
*   Ability to work with proprietary data securely and responsibly.
*   Currently pursuing a Bachelor's or Master's degree in Computer Engineering, Electrical Engineering, or related field.
